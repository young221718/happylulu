# Windows 대화형 화면 QA

`Run-Interactive-QA.cmd`를 실행하면 실제 오늘 창과 설정 창을 합성 출근 기록으로 표시합니다. QA 창을 닫거나 **QA 종료**를 선택하면 종료합니다. `HappyLulu.UiChecks.exe`에 인수를 주지 않으면 기존 자동검사를 실행합니다.

CI 패키지는 .NET 네이티브 런타임도 단일 실행 파일에 포함하며 실행 시 임시 위치에 풉니다. CI는 최종 ZIP을 별도 위치에 풀어 인수 없는 자동검사 실행까지 확인합니다.

- 기록은 실행할 때마다 새로 만든 `%TEMP%\happylulu-interactive-<고유값>\state.json`에만 저장합니다. 경로는 QA 창과 설정에서 확인할 수 있습니다. 기존 HappyLulu 출근 파일을 읽거나 변경하지 않습니다.
- 테스트 시각은 실행 당일 17:00으로 고정됩니다. 오늘 09:00과 과거 기록이 제공되며, **테스트 기록 초기화**는 이 합성 기록만 다시 만듭니다.
- Windows 자동 실행 변경은 비활성화됩니다. 잠금 해제 감지와 프로덕션 트레이 상주는 실행하지 않습니다.
- 언어·출근 시각·근무 유형·월별 기록·창 크기와 키보드 동작을 수동 확인하는 도구입니다. 실제 트레이·잠금 해제·로그인 자동 실행 검증을 대신하지 않습니다.

임시 기록은 종료 후에도 남아 있어 검증 중 저장 결과를 확인할 수 있습니다. 개인 데이터가 없는 새 파일입니다. 이 QA 도구는 공개 릴리즈가 아니며 앱 설치를 대체하지 않습니다.
