# AI 사용량: 공개 Codex 기능

Mac 1.5.21은 이전 공개 버전 1.5.20의 Codex 사용량 기능을 유지합니다. 개발판에서 추가했던 Antigravity·다중 계정 관리·토큰 속도 측정은 포함하지 않습니다.

## 표시와 설정

플러그인 관리에서 AI 사용량을 설치하고, 설치된 플러그인 → AI 사용량의 **사용량 보기**를 켭니다. 처음 설치하면 꺼져 있으며 사용을 꺼도 설치와 설정은 보존합니다. 사용 중에는 메뉴 패널의 사용량 행으로도 상세 설정을 엽니다.

Codex ChatGPT 계정의 주간 잔여 한도·초기화 시각·마지막 조회와 관측 이력 기반 시간당 소모율을 표시합니다. API 키 계정·모델별 토큰 사용량·요금·출력 토큰 속도가 아닙니다. 주간 한도가 없으면 알 수 없는 값으로 표시하고 단기 한도를 주간 값으로 대체하지 않습니다. 오래된 조회 값은 구분하며 계정이 바뀌면 관측 이력을 분리합니다.

메뉴바는 Codex 이름+%, 단색 아이콘+%, %만 중에서 선택합니다. 기본은 이름+%, 5분마다 갱신, 알림 끔입니다. 갱신은 1/5/10/15/30분, 잔여량 알림 기준은 10/20/30% 중에서 고릅니다. 알림은 시스템 권한과 활성화 상태를 확인합니다.

## 계정과 연결

Codex 연결에서 실행 파일 선택·자동 찾기·ChatGPT 로그인·로그인 취소를 제공합니다. 기존 Codex CLI 로그인을 사용하며 다른 계정으로 로그인하면 해당 CLI 계정도 변경됩니다. 예전에 선택한 Codex의 별도 계정 폴더가 있으면 그대로 사용하고 경로를 연결 화면에 표시합니다. 이번 버전에서는 계정 목록을 추가·전환하지 않습니다.

이전 개발판의 연결 JSON·프로필별 이력·알림 상태는 덮거나 삭제하지 않습니다. 공개 Codex 설정과 새 관측 이력은 별도 저장 공간에 둡니다. 정상적인 이전 단일 Codex 설정 또는 명확히 선택된 Codex 연결만 가져옵니다. Antigravity/다른 공급자·불명확한 선택은 자동 조회나 로그인을 시작하지 않고 실행 파일 선택을 안내합니다. 새 공개 설정이 손상되면 원본을 보존하고 조회·변경을 중지합니다.

새 공개 관측 이력은 첫 조회부터 쌓입니다. 이전 개발판의 공급자별 이력을 다른 계정의 사용량으로 합치지 않습니다. CLI 로그인 파일을 삭제하거나 읽어 문서로 수집하지 않습니다.

## 고정 개발 앱에서 사용

고정 `happylulu-dev` / `local.chanyoung.HappyLulu.Dev.manual-leave.20261015`에서는 사용자가 켠 AI 사용량과 두 로컬 Mac 유틸리티만 실행할 수 있습니다. 캘린더·다우오피스·휴가 자동 인식·자동 출근·자동 업데이트·로그인 항목 변경은 계속 차단합니다. Dev와 운영 앱의 플러그인 설정은 분리되지만 기본 Codex CLI 로그인은 공유될 수 있습니다.

## 검증

`swift test --build-system native --filter AIUsageTests`는 주간 한도·갱신·취소·로그인·알림·표시와 저장 호환 경계를 합성 데이터로 검사합니다. 원본 JSON 불변, 다른 공급자 실행 차단, Codex 계정 폴더 보존, 손상 데이터 읽기 전용, 명시 연결 후 재시작을 포함합니다. 실제 계정 서버 응답·브라우저 로그인·알림 권한·공개 업데이트 설치는 별도 확인입니다.
