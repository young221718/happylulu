# 시스템 러너 · 로컬 개발 후보

2026-10-22 CPU 러너를 로컬 시스템 지표 표시로 확장한 Mac용 개발 후보입니다. 표시 이름은 시스템 러너이며 기존 플러그인 ID `cpu-runner`와 동물 선택 설정을 유지합니다. 현재 공개 Mac 1.5.19에는 포함되지 않습니다. Windows 트레이 구현과 공개 배포는 범위 밖입니다.

## 사용

설정 → 플러그인 → 시스템 러너 → 설치 → 플러그인 사용을 켭니다. 기본 표시 방식은 **부엉이 눈빛**입니다. 기존 부엉이 눈 모양을 유지하고 테두리의 빛만 CPU 사용량에 따라 회전합니다. 표시 방식을 **동물**로 바꾸면 기존 햄스터·토끼·고양이 중 저장한 선택을 사용합니다. 표시 방식을 바꿔도 동물 선택은 지우지 않으며 두 설정 모두 재실행 후 유지됩니다. 해당 메뉴바 항목을 클릭하면 출퇴근 팝오버에서 시스템 요약을 확인하고, 플러그인 설정에서 상세 수치와 표시 방식을 확인합니다.

빛의 한 바퀴는 CPU 0%에서 4.8초, 100%에서 0.9초이며 중간 사용량에서는 선형으로 빨라집니다. 회전 위치는 48단계이고 실제 경과 시간으로 진행해 타이머가 늦어져도 회전 주기를 유지합니다. 화면 갱신은 최대 24fps, 저전력 모드에서는 12fps입니다. CPU 측정 전·실패·동작 줄이기 상태는 0번 위치에 멈춥니다. 동물 모드의 기존 CPU 속도 정책은 유지합니다.

부엉이 모드에서 **시작색·끝색**을 macOS 기본 색상 선택기로 바꿀 수 있습니다. 가운데 그라디언트 견본에 두 색을 표시하며 불투명 색상만 사용합니다. 기본값은 하늘색 `#14C9FF`와 보라색 `#AD58FF`이고 **기본색 복원**으로 되돌립니다. 색 변경은 회전 위치·타이머를 바꾸지 않고 즉시 반영하며 동작 줄이기로 멈춘 상태에서도 적용됩니다. 동물 모드에서는 색 컨트롤을 숨깁니다.

요약과 상세 화면에는 CPU 사용률, 메모리 사용량/전체 용량과 macOS 메모리 압력, 시동 디스크 용량, 네트워크 수신·송신 속도, 배터리 충전량과 전원 상태를 표시합니다. 읽을 수 없는 항목과 첫 속도 측정 전에는 `—` 또는 측정 상태를 표시하며 0으로 꾸미지 않습니다. 배터리가 없는 Mac은 `배터리 없음`으로 구분합니다.

메모리와 네트워크는 CPU와 함께 1초마다 갱신하고 디스크·배터리는 5초 동안 캐시합니다. 디스크의 사용 가능 공간은 macOS의 중요 사용 기준이며 정리 가능한 공간을 포함합니다. 네트워크는 연결된 물리 Wi-Fi·유선 인터페이스의 합산 bytes/s입니다. VPN·가상 인터페이스는 제외하며, 인터페이스 연결 상태가 인터넷 접속 성공을 뜻하지는 않습니다. 메모리 압력은 macOS가 제공하는 경우만 표시합니다.

플러그인을 끄면 빛·캐릭터·시스템 측정·애니메이션을 종료하고 표시 방식·동물 선택은 보존합니다. 잠자기 중에는 빛을 지우고 작업을 중단하며 깨어나면 CPU와 회전 시간을 새 기준으로 측정합니다. macOS의 동작 줄이기는 애니메이션을 멈추고, 저전력 모드는 화면 갱신 빈도를 제한합니다.

## 기능·디자인 경계

- **확장 HL-RUNNER-001:** 시스템 러너 1개, 부엉이 눈빛 기본 표시·기존 동물 모드, 선택 저장, CPU 변화에 따른 움직임, 시스템 지표 5종.
- **재사용 HL-PLUGIN-001 / HL-UI-011:** 내장 플러그인 목록의 설치와 활성화, 설정 화면. 처음부터 자동 설치하거나 켜지 않습니다.
- **유지 HL-UI-001:** 기존 부엉이 8상태·휴가 전날 장식·퇴근 시각·메뉴바 클릭 동작.
- **유지 HL-PLUGIN-002:** 일정·휴가·반차 연결. 시스템 러너는 해당 연결 후보에 나타나지 않습니다.
- **설정 규칙:** 왼쪽 설명, 가운데 표시 방식 설명·그라디언트 견본·동물 예시, 오른쪽 선택. 색 행은 부엉이 모드, 동물 행은 동물 모드에서만 표시하며 기존 플러그인 사용 토글을 재사용합니다.
- **그림:** 햄스터·토끼는 기존 26×18pt 8프레임, 고양이는 Kyome22/menubar_runcat 공식 앱의 원본 28×18pt 5프레임입니다. 모두 1×/2× 렌더를 캐시합니다. 동물 이름과 CPU 상태를 접근성 이름으로 제공합니다. 원본 PNG·라이선스·고정 커밋과 해시는 `Sources/CPURunnerIntegration/Resources/RunCat/`에 있습니다.

과거 그림 수락 이력은 아래에 보존합니다. 이후 사용자는 고양이 대신 기존 부엉이 눈을 고정하고 테두리 빛을 회전하는 방향을 승인했습니다. 공식 RunCat 원본을 포함한 기존 동물 그림은 선택 모드로 보존합니다. 방향 승인과 현재 앱의 실제 렌더·사용자 수락은 구분합니다.

## 구현 경계

`CPURunnerIntegration`은 `AppPluginCore`·`AppPluginHost`만 참조합니다. 앱 조립부가 모듈을 등록하며, 단일 메뉴바 항목은 호스트가 소유합니다. 부엉이 모드에서는 추가 동물 이미지 없이 `PluginBaseIconEffect.orbit(phase:palette:)`와 접근성 상태를 제공하고 호스트가 부엉이 위에 빛을 그립니다. 동물 모드에서는 기존 이미지 콘텐츠를 제공합니다. 일정 기능을 제공하지 않는 빈 기능 어댑터를 사용합니다. 표시 방식 키는 `HappyLuluRunnerPresentation`, 동물 설정 키는 기존 `HappyLuluRunnerAnimal`이며 설치·활성화는 기존 플러그인 카탈로그에 저장합니다.

시작색·끝색은 `HappyLuluRunnerOrbitStartColor`와 `HappyLuluRunnerOrbitEndColor`에 각각 `#RRGGBB` 문자열로 저장합니다. 형식이 잘못된 값은 해당 색의 기본값으로 표시하며 읽기만으로 원본 값을 덮어쓰지 않습니다. 색상 선택기는 sRGB로 변환하고 8비트 RGB로 정규화합니다.

CPU는 로컬 시스템 누적 카운터의 차이를 1초마다 측정합니다. 화면 프레임만 별도 타이머로 바꾸며 매 프레임 설정 화면을 다시 게시하지 않습니다. 지표 화면이 컨트롤러를 직접 관찰하므로 정상 수치 갱신이 호스트의 일정 화면 재조회를 일으키지 않습니다. 상주 측정은 자동 업데이트를 막는 `isRunning` 작업으로 취급하지 않습니다. 로컬 네트워크 인터페이스 카운터만 읽으며 외부 접속 요청·계정·캘린더 접근은 추가하지 않습니다.

## 2026-10-22 로컬 확인 결과

CPU 계산·세 동물 저장·수명주기 검사, 그림 250개 assertion, 기존 출퇴근·플러그인 구조·설정 이동·휴가 전날·자동 업데이트·다우오피스 제거 빌드 검사를 통과했습니다. 설정은 500pt에서 세 동물×한국어/영어×밝음/어두움 12개를 렌더했습니다. CPU 35%는 합성 예시값입니다.

실제 마우스·키보드 수락 도구는 연결 오류가 발생해 UI 조작 성공으로 기록하지 않았습니다. 이 문서의 구현·자동 검사와 공개 릴리즈·사용자 수락은 별개입니다.

## 2026-10-22 시안 충실도 수정

최초 로컬 후보의 그림은 사용자 검토에서 제안 시안과 머리·몸·다리 비율이 다르다는 지적을 받았습니다. 기능 및 렌더 검사는 디자인 충실도를 보장하지 않습니다. 원안 아래쪽의 단색 캐릭터를 기준으로 큰 머리·통통한 몸·짧은 둥근 발을 다시 그리고, 햄스터의 둥근 귀·토끼의 길고 둥근 귀·고양이의 열린 갈고리 꼬리를 복원했습니다. 색상 시안이나 기존 부엉이를 교체하는 작업은 아닙니다.

디자인 검토에서는 원안·이전 프레임·새 프레임을 같은 높이로 비교하며, 26×18pt 실제 크기와 2× 확대, 밝음·어두움, 8프레임을 따로 확인합니다. 자동 검사와 독립 검토를 마쳐도 최종 외형 수락은 사용자 확인으로 남깁니다.

수정한 최종 소스로 그림 250개 assertion, CPU 러너 회귀 검사, 설정 12개 렌더, 앱 빌드·서명을 다시 통과했습니다. 독립 정적 시각 검토에서 중대한 캐릭터 정체성 이탈을 추가로 찾지 못했지만, 토끼 귀의 각도와 작은 세부는 26pt에 맞춘 단순화가 남습니다. 원안과 픽셀 단위로 동일하다는 뜻은 아닙니다.
