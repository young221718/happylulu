# happylulu QA 파이프라인

## 범위

Mac에서 반복 실행하는 자동 회귀 검사, 격리된 실제 뷰의 화면 조작, 결과 증거를 연결한다. 기존 Mac·Windows 계산과 배포 검사를 유지한다. 이 문서의 절차는 공개 릴리즈, 개인 캘린더 동기화, 계정 로그인, 설치 앱 교체를 자동 승인하지 않는다.

기존 CI를 복제한 새 작업을 추가하는 대신 Mac workflow의 검사 호출을 공통 실행기로 묶는다. 새 의존성이나 별도 상주 서버는 필요 없다. Windows 빌드·공통 계산·패키징은 기존 Windows workflow가 담당하며 Mac의 화면 검사 결과로 Windows GUI를 통과 처리하지 않는다.

## 자동 실행

개인 Mac에서는 실행 전에 모든 GUI 경로가 단일 `happylulu-dev` 이름·식별자를 지키는지 확인한다. 현재 별도 앱을 만드는 Design·Navigation·EditMenu·PanelFocus·Appearance·Vacation·AutoInstall·Login·SignedAuto·RuntimeProfile 경로와 이를 포함한 QA 실행기는 전환 전까지 개인 Mac에서 실행하지 않는다. 이번 변경은 AI 사용량 QA의 고정 정체성 적용이며 전체 QA 전환은 후속 작업이다. 기존 검사 계약을 삭제하거나 `skip`으로 통과 처리하지 않고, 전환 후에도 같은 검증을 유지한다.

```sh
python3 scripts/check-qa-runner.py
python3 -B -m unittest discover -s scripts/tests -p 'test_ai_usage_ui_cli.py' -v
python3 scripts/run-qa.py --profile smoke
python3 scripts/run-qa.py --profile full
```

`smoke`는 근무·캘린더·시스템 지표 및 핵심 UI 회귀를 빠르게 확인한다. `full`은 기존 Mac CI의 전체 검사 목록을 실행한다. 공개 배포 패키징과 Sparkle 검증은 workflow의 기존 단계에서 이어진다. 정확한 목록과 명령은 실행기의 검사 정의와 각 결과 보고서를 따른다.

각 실행은 고유한 결과 폴더를 만들고 커밋, 작업 파일 변경 여부, 실행 환경, 명령, 소요 시간, 종료 코드, 로그, 합성 화면 증거를 기록한다. 기존 결과 폴더를 덮어쓰지 않는다. 검사 전체 예산은 25분이며 시간 초과·취소 시 실행한 자식 프로세스를 종료하고 남은 검사를 차단 상태로 기록한다. 미추적 코드 파일도 내용 지문에 포함하고 종료 시 다시 비교한다. 렌더링 옵션마다 별도 하위 폴더를 사용한다. 환경 변수 전체, 개인 기록, 토큰, 계정 원문은 수집하지 않는다.

| 결과 | 의미 |
| --- | --- |
| passed | 해당 자동 명령이 성공했고 명시된 건너뜀을 발견하지 않음 |
| partial | 명령은 성공했으나 `SKIP` 또는 `LIMIT`로 표시한 검증 공백이 있음 |
| failed | 검사 실패 또는 제한 시간 초과 |
| blocked | 필수 도구·선행 빌드 등의 부재로 실행하지 못함 |
| not-applicable | 명시적으로 제외한 선택 모듈의 검사 |
| invalidated | 실행 도중 소스가 바뀌어 실행 결과와 최종 소스가 일치하지 않음 |

`partial`은 기존 CI에서 허용하던 건너뜀을 보존하므로 자동 명령 종료 코드는 0일 수 있다. 보고서의 전체 커버리지는 완료로 표시하지 않는다. 실패와 필수 검사 차단은 0이 아닌 종료 코드를 반환한다. GitHub의 초록 체크만으로 실제 화면 조작·권한·실서비스 연결까지 통과했다고 판단하지 않는다. CI는 실패해도 이미 만들어진 보고서·로그·합성 화면을 업로드한다.

## 직접 조작하는 격리 QA

```sh
bash scripts/check-ai-usage-ui.sh --interactive
```

이 명령은 실제 `PanelView`·`SettingsView`를 사용하는 `happylulu-dev`를 유지한다. 개발·QA GUI 앱은 이 이름과 기존 고정 식별자 `local.chanyoung.HappyLulu.Dev.manual-leave.20261015`만 사용한다. QA·날짜·UUID를 붙인 별도 앱 식별자를 만들거나 실행하지 않는다. 이 AI 사용량 자동 검사도 같은 앱 정체성을 사용한다.

합성 앱 경로는 사용자 임시 폴더의 `happylulu-dev-synthetic/happylulu-dev.app`으로 고정한다. 실행 잠금으로 다른 checkout의 합성 QA와 동시에 실행하지 않으며, 같은 Dev 식별자의 앱이 실행 중이면 종료를 요청하고 시작을 거부한다. 이전 실행의 파일이나 잠금이 남았으면 내용을 보존·정리한 뒤 다시 실행한다. 종료 시 정확한 합성 앱 경로를 Launch Services에서 등록 해제한 뒤 앱과 임시 데이터를 제거한다. 등록 해제에 실패하면 실패를 보고하고 재시도용 앱·잠금을 보존한다. 다른 설치 앱이나 등록 전체를 초기화하지 않는다.

가짜 Codex 사용량·시스템 지표·근무 기록은 합성 데이터 폴더에 두고, 언어·퇴근 시각 표시·러너·AI 사용량 설정은 메모리에서만 사용한다. 기존 정식/Dev 환경설정 도메인을 지우거나 합성 값으로 덮어쓰지 않는다. 자동 검사와 달리 명시적으로 `--interactive`를 준 경우에만 창을 유지하며 CI에서는 거부한다.

QA 앱의 외부 권한·계정 흐름은 검사 대상에서 분리한다. 캘린더 실행, 로그인 항목 변경, 자동 업데이트, 실서비스 조회를 시작하지 않는다. 선택 가능한 외부 플러그인을 제한하고 알림 권한 변경은 비활성화한다. 실제 계정과 비밀번호는 입력하지 않는다. QA 앱에서의 성공은 개인 계정 연결 성공을 뜻하지 않는다.

| 시나리오 | 확인할 결과 |
| --- | --- |
| 메뉴·설정 | 실제 클릭으로 설정 창 이동, 중복 창이나 멈춤 없음 |
| 출근 시각 편집 | 클릭으로 편집 진입, Cmd+V/문맥 메뉴 붙여넣기, 유효 입력 반영·잘못된 값 거부 |
| 일반 설정 | 언어 선택과 토글의 3열 정렬, 표시 단위와 퇴근 시각 옵션 즉시 반영 |
| 외관 | 기존 테마와 Liquid Glass 표시, 선택 유지, 제목줄·버튼 잘림 없음 |
| 시스템 러너 | 부엉이 눈 모양 유지, 시작·끝 색 변경, 기본값 복원, 동물·시스템 지표 표시 |
| AI 사용량 | Codex 글자·아이콘·퍼센트 선택, 플러그인 설정 노출·복귀 |
| 시간 갱신 | 고정 합성 시나리오에서 야근 90분에서 91분으로 갱신되는 자동 증거 확인 |
| 접근성 | 키보드 탐색·VoiceOver·대비 및 투명도 설정의 실제 화면 수락은 별도 확인 |

대화형 fixture 시계는 1초마다 진행하며 운영 앱의 0.1초 갱신 주기를 검증한 것으로 간주하지 않는다.

실제 클릭·키 이벤트는 화면 조작 도구로 관찰한 결과를 기록한다. Mac이 잠겨 있으면 사용자가 직접 잠금을 해제할 수 있을 때까지 해당 항목은 차단 상태로 남기고 자동 검사만 진행한다. 모델 메서드 호출이나 offscreen 이미지는 이 항목의 대체 증거가 아니다. 도구 연결 실패, 키 창 부재, 캡처 권한 부족은 차단/미검증으로 남긴다. `.window.png`와 offscreen `.png`를 구분한다.

## 결과 기록과 완료 기준

자동 결과에는 실행 날짜·커밋·환경과 각 검사 결과를 포함한다. 직접 QA 기록에는 QA 앱 식별자, 시나리오, 관찰 결과, 증거 경로를 적는다. 수정 후에는 영향을 받는 검사만 재실행하고, 변경된 소스와 결과의 연결을 유지한다.

현재 실제 사용자 환경의 캘린더 전체 접근, 다우오피스 키체인 승인 뒤 조회, 로그인·잠금 해제, Intel·최소 macOS·Windows 실기기, Apple 공증·공개 업데이트는 별도 확인 항목이다. 기존 날짜가 붙은 검증 이력은 [플랫폼 검증 기록](PLATFORM-VALIDATION.md)에 보존한다.
