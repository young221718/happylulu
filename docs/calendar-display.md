# 캘린더 복사본 표시

같은 일정의 복사본을 오늘 일정, 월 달력의 미리보기·추가 건수와 선택한 날짜 목록에서 한 번 표시합니다. 이 처리는 **화면에 전달하는 투영**에만 적용합니다. Mac 캘린더의 원본, 플러그인의 원본 스냅샷, 동기화 매핑과 업스트림 일정은 수정하거나 삭제하지 않습니다. 합쳐진 표시 값에는 원본 캘린더 ID 목록을 보존합니다. 실제 달력의 날짜별 일정 행에는 조회 가능한 원본 캘린더 이름을 모두 표시합니다. 이름이 일부 없으면 확인한 이름을 표시하고, 모두 없거나 플러그인이 캘린더 이름을 제공하지 않으면 선택한 기능 출처 이름으로 표시합니다. 다우오피스 출처의 ID를 Mac 캘린더 이름으로 해석하지 않습니다.

## 일치 규칙

같은 기능 출처 안에서 서로 다른 캘린더의 일정만 비교합니다. 제목, 비교용 시작·종료 경계, 종일 여부와 장소가 정확히 같아야 합니다. 공백만 있는 제목, 길이가 없거나 잘못된 시간 범위, 같은 캘린더의 여러 후보는 합치지 않습니다. 비교를 위해 제목을 줄이거나 대소문자·공백을 정규화하지 않습니다.

Mac 캘린더는 정규화한 메모·알림과 일반 URL도 비교합니다. 시간 일정은 시간대 이름 대신 절대 시각으로 비교합니다. 종일 일정은 원본의 다음 날 자정 종료와 복사본의 마지막 날 `23:59:59` 종료를 같은 배타적 civil-day 경계로 비교합니다. 이 경계는 원본을 해석한 시간대에서 계산하므로 DST의 23·25시간 날짜도 보존합니다. 화면과 원본의 시작·종료값은 변경하지 않습니다. HappyLulu가 복사본을 식별하는 URL 표식은 내용 차이에서 제외합니다.

1. 현재 선택한 캘린더 쌍의 저장된 동기화 매핑에서 캘린더 ID와 일정 ID가 정확히 일치하면 그 매핑을 우선 사용합니다. 삭제 기준선이나 여러 매핑이 겹친 경우에는 매핑을 추정하지 않습니다.
2. 매핑이 없으면 서버 UID를 사용합니다. 반복 일정은 시리즈 UID만 사용하지 않고 **원래 회차 날짜를 포함한 ID**를 사용합니다. 옮긴 회차도 원래 회차 ID로 구분합니다. 원래 회차 날짜가 없거나 관리된 일반 복사본이 시리즈로 바뀌어 회차를 확인할 수 없으면 합치지 않습니다.
3. 신뢰할 식별자가 다른 일반 일정도 비교 내용이 완전히 같고 후보가 정확히 두 건이며 각 캘린더에 한 건씩이면 한 번 표시합니다. Mac의 반복·초대·부동 시간 일정이나 읽을 수 없는 알림 메타데이터에는 이 내용 기반 대체 규칙을 적용하지 않습니다.

같은 표시 내용에 여러 반복 회차가 겹치면 먼저 신뢰할 식별자별 부분집합을 각각 묶고, 그 뒤 남은 후보에만 내용 기반 대체 규칙을 적용합니다. 따라서 회차 두 개의 복사본 네 건은 두 건으로 표시합니다. 이미 묶은 표시 값을 오늘 일정에서 재사용할 때는 그 그룹을 다른 후보와 내용만으로 다시 합치지 않습니다. 같은 식별자의 후보가 한 캘린더에 여러 건이면 추정해 짝짓지 않습니다.

식별자가 같아도 비교 내용이 다르면 두 건을 모두 표시합니다. 한쪽의 제목·시간·메모·장소·알림·일반 URL이 바뀌면 차이를 숨기지 않습니다. 원본 한쪽이 사라지면 다음 조회의 남은 일정이 계속 표시됩니다. 표시 대표는 기존의 출처·캘린더·일정 ID로 결정하므로 조회 순서가 바뀌어도 같습니다. 이 선택은 동기화의 원본·대상이나 쓰기 정책을 바꾸지 않습니다.

## 한계

식별자가 다른 별개의 일반 일정 두 건이 모든 비교 필드까지 정확히 같으면, 수동으로 만든 복사본과 자동 구별할 수 없습니다. 위의 제한된 내용 기반 대체 규칙은 이 경우에도 한 건을 표시할 수 있습니다. 반대로 여러 후보, 메타데이터 차이, 확인할 수 없는 반복 회차는 중복처럼 보여도 별도로 남깁니다.

플러그인 스냅샷은 해당 공개 계약이 제공하는 제목·시간·종일 여부만 비교합니다. 계약에 없는 메모·참석자·서버 UID를 추정하지 않습니다. 서로 다른 기능 출처를 동시에 합치지 않습니다. 계정 변경과 실제 EventKit 서버별 UID 동작은 합성 회귀 검사와 별도로 확인해야 합니다.

## 검증

- `swift run --build-system native --jobs 2 AppPluginChecks`: 표시 투영, 원본 보존, 추가 건수, 모호한 후보, 원본 소실·변경, 시간대와 DST·종일 배타적 종료일.
- `swift run --build-system native --jobs 2 CalendarSyncServiceChecks`: 합성 EventKit 스냅샷의 서버 UID·동기화 매핑·원래 반복 회차·메모·알림·URL 경계.
- `bash scripts/check-plugin-architecture.sh`: 실제 기능 달력 모델의 월·날짜 투영과 출처 전환. 빌드 병렬도는 2로 제한해 실행합니다.

모든 신규 검사는 합성 데이터만 사용합니다. 실제 계정 연결, 캘린더 권한 요청, 앱 설치·실행 또는 업스트림 변경을 포함하지 않습니다.
