# 다우 개인 세션의 휴가·오늘 출근 반영

2026-11-17, 이슈 #76의 로컬 구현 계약입니다. 설치·배포나 실제 계정 검증을 뜻하지 않습니다.

## 사용과 보존 정책

다우 플러그인에 개인 ID·비밀번호로 연결하고 **휴가 현황 출처를 다우오피스**로 선택합니다. 기존 연차 잔여·사용·총 일수, 승인 상태·날짜가 있는 휴가, 이번 달 일정을 계속 조회합니다. 잔여 일수는 조회용이며 로컬 근무 유형으로 환산하지 않습니다.

설정 → 다우오피스 → **HappyLulu에 반영**에서 오늘의 변경 전후 값을 확인합니다. 새 제안이 있으면 메뉴 패널에 해당 설정을 여는 항목이 표시됩니다. 기본은 제안이며 **수정 / 출근 시각 수정**을 눌러야 기록이 바뀝니다. **현재 값 유지**는 같은 날짜·원본 값·로컬 값에 대한 재조회/재시작의 중복 제안을 막습니다. 조회 시각만 달라져도 다시 묻지 않습니다.

**수정 제안을 macOS 알림으로 받기**는 기본 꺼짐입니다. 설정에서 직접 켤 때만 시스템 알림 권한을 요청합니다. 허용하면 앱이 백그라운드에 있어도 새로운 수정 제안에 대한 로컬 알림을 보내며, 알림을 누르면 다우오피스 설정을 엽니다. 알림에는 개인 날짜·시각·연차 값 없이 수정 여부를 확인하는 문구만 표시합니다. 권한을 거부하거나 알림을 꺼도 앱 안의 수정 제안은 유지합니다.

알림 이력은 제안별 해시로 보존하여 반복 조회·재시작 때 같은 알림을 다시 보내지 않습니다. 수정·거절·연결 해제·기능 종료 또는 알림 끄기는 대기 작업을 무효화하고 해당 알림을 제거합니다. 이미 시스템에 제출한 요청이 늦게 완료되면 식별자를 다시 제거하며 새 발송을 시작하지 않습니다. 운영체제가 이미 보여 준 배너를 소급하여 없었던 것으로 만들 수는 없습니다. `daou-review-` 식별자만 다우 설정으로 연결하고, 기존 AI 알림 식별자·내용과 전경 표시 정책은 유지합니다.

전일 휴가와 출근 시각에는 각각 기본 꺼짐인 자동 반영 옵션이 있습니다. 수동 출근·수동 근무 유형·기록 안 함과 충돌하면 자동 반영 대신 확인을 요구합니다. 다우에서 반영한 출근 시각은 같은 자동 반영 옵션으로 갱신할 수 있지만 사용자가 시각을 직접 수정하면 외부 소유 표시를 해제하여 이후 자동 덮어쓰기를 막습니다. 출근 기록에는 다우 출처를 표시합니다.

- 휴가: 최근 15분 이내의 `APPROVAL` 상태인 명시적 전일 연차·공가만 비교합니다. 한 날짜의 정확한 1일 또는 선택된 날짜 수와 일수가 일치하는 전일 휴가를 지원합니다. 일반 휴가·0.5일로 오전/오후 반차를 추정하거나 기간 중 빠진 날짜를 채우지 않습니다.
- 출근: 오늘의 실제 시각이 없거나 다를 때만 제안합니다. 초 단위 원본 시각·시간대를 보존하며 일반 수동 입력의 시간 창 밖인 실제 출근도 임의 시각으로 바꾸지 않습니다. 출근 시각 반영은 기존 근무 유형과 기록 안 함 선택을 바꾸지 않습니다.
- 앱과 원본의 오늘 날짜가 다르거나 시각이 미래·다른 날짜·15분 초과·해석 불가이면 반영하지 않습니다. 빈 조회를 00:00으로 저장하지 않습니다.
- 원본 휴가 취소·미승인·누락·조회 오류는 로컬 기록을 지우거나 취소하지 않습니다. 이미 반영한 근무 유형은 사용자가 확인해서 변경합니다. 전일 휴가 반영은 원래 출근 기록을 삭제하지 않습니다.

자동 반영 선택과 마지막 거절의 해시는 출근 상태 파일 옆 `<상태 파일>.daou-review.json`에 저장합니다. 비밀번호·쿠키·원본 출근 응답은 저장하지 않습니다. 설정이 손상되면 원본 파일을 보존하고 자동 반영/설정 덮어쓰기를 중지합니다. `Arrival.externalSourceID`는 선택적 필드이며 이전 기록은 그대로 읽습니다. 저장된 `source`는 기존 `manual` 값이므로 이전 앱의 enum 디코딩도 유지합니다. 수동 시각 편집과 서버 반영은 별개 경로입니다.

## 개인 웹 API 근거

기존 개인 ID·비밀번호 세션과 동일한 회사 origin에 아래 **읽기 전용 GET**을 추가합니다.

```text
GET /api/attend/normal/gadget/today
Content-Type: application/json
```

2026-11-17 익명으로 제공되는 [개인 근태 화면](https://lululab.daouoffice.com/ehr/app/attend/my-attendance-status)의 [공개 JavaScript](https://lululab.daouoffice.com/_next/static/chunks/0_rgdfb5iz9xw.js)에서 GET 경로, JSON의 `data`, `data.startWorkTime`·`data.endWorkTime`·`data.zoneId` 사용을 확인했습니다. 해당 asset의 SHA-256은 `ab698c039dfbe9d7da8ab96096a3276b9637300d40e1c233f8bda048c9051040`입니다. 익명 API 요청은 HTTP 401 JSON이며 실제 인증 후 응답은 이 작업에서 조회하지 않았습니다.

구현은 검증 가능한 명시적 offset의 ISO 8601 시각만 해석합니다. `startWorkTime: null`은 기록 없음, 데이터/필드 누락과 미지원 형식은 조회 불가로 구분합니다. 실제 회사 응답이 다른 형식이면 해당 형식의 비식별 응답 구조 확인과 fixture가 먼저 필요합니다. 화면에 사용되는 나머지 근태 필드와 퇴근 시각은 수집하지 않습니다.

출근 API가 401/403/404·네트워크 오류·미지원 응답으로 실패해도 이미 성공한 휴가·일정 조회를 실패로 바꾸지 않습니다. 출근 필드는 조회 불가로 표시하고 저장된 출근을 유지합니다. 이 API의 응답 본문은 성공/오류 모두 로그에 남기지 않습니다. 기존 로그인/세션 갱신 흐름과 같은 HTTPS origin 제한을 사용합니다. 회사 관리자 OpenAPI·회사 전체 임직원 조회·근태 등록 POST는 호출하지 않습니다.

## 검증

합성 fixture만 사용하며 실제 계정·키체인·Dev/운영 preferences·앱 등록·출퇴근 서버 변경을 수행하지 않습니다.

```sh

bash scripts/check-daouoffice-leave-review.sh
swift run --build-system native --jobs 2 AfterSixChecks
swift test --build-system native --jobs 2
python3 scripts/check-qa-runner.py
git diff --check
```

`AppPluginChecks`는 정확한 개인 GET·동일 origin·인증 재사용·ISO/시간대·null·잘못된 응답·optional 401/404/500 보존과 개인정보 로그를 검사합니다. headless integration은 제안/수락/거절·재시작 중복 억제·각 자동 옵션·수동 충돌·출처/초 보존·누락·취소·오래된 응답·날짜/시간대·손상 설정을 검사합니다. `run-qa.py --profile full`에도 두 검사 경로를 연결합니다.

같은 headless integration에서 표시하지 않은 실제 `NSPopover.contentSize`의 제안 발생·수락·거절 크기와, fake notification transport의 기본 꺼짐·명시 권한 요청·권한 거부·재조회/재시작 중복 억제·비활성 host·끄기/수락/거절 뒤 지연 응답·시스템 제출 후 지연 완료 정리·AI 식별자 분리를 검사합니다. 테스트에서는 실제 시스템 권한을 요청하거나 실제 알림을 보내지 않습니다. 네이티브 배너·권한창·알림 클릭의 실사용 수락은 별도 미검증입니다.

실제 개인 세션 로그인 후 출근 응답·실제 회사의 근태 권한·사용자 화면 수락은 별도 미검증입니다. 공개 JS 확인, 합성 검증, 실제 로그인 조회, 앱 설치/배포는 서로 다른 증거입니다.
