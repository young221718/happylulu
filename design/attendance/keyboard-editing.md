# 출근 시각 키보드 편집

2026-11-17 · [이슈 #74](https://github.com/young221718/happylulu/issues/74)

메뉴바 패널의 HH:mm 네 자리, 자리별 +/− 버튼과 기존 크기를 유지한다. 마우스로 각 자리를 다시 선택하지 않아도 시·분을 연속 입력할 수 있게 한다.

| 입력 | 동작 |
| --- | --- |
| 숫자 | 현재 자리를 바꾸고 다음 자리로 이동한다. `0930`을 연속 입력하면 `09:30`이 된다. 마지막 자리는 포커스를 유지한다. |
| Tab / Shift+Tab | 시에서 분의 첫 자리로, 분에서 시의 첫 자리로 이동한다. 시간 입력 바깥 방향의 Tab은 기존처럼 편집기를 벗어난다. |
| 오른쪽 / 왼쪽 방향키 | 한 자리씩 이동하며 시·분 사이의 콜론도 넘어간다. 첫·마지막 자리에서 바깥 방향키를 누르면 현재 자리를 유지한다. |
| Return / 숫자패드 Enter | 네 자리 전체를 기존 검증 경로로 저장한다. 유효하지 않거나 미래 시각이면 오류와 초안을 유지한다. |
| Escape | 저장하지 않고 취소한다. |

붙여넣기, 외부 클릭·패널 닫기에 저장, 날짜·시간대·근무 유형 검증은 유지한다. 내부 자리 이동과 마지막 숫자 입력만으로 저장하지 않는다. 접근성 이름은 시/분·십/일의 자리를 계속 구분한다.

자동 검증은 `scripts/check-clock-paste.sh`의 AppKit 키 이벤트·연속 입력과 `scripts/check-panel-focus.sh`의 실제 PanelView·격리 저장소·세 시간대 저장 검사를 사용한다. CLI 호스팅 검사는 실제 설치 앱의 사용자 수락·VoiceOver 검증과 구분한다.
