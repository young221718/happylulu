# HappyLulu 디자인 목차

앱과 소개 사이트의 화면·상태·상호작용 및 자산을 찾는 진입점이다. 기존 문서와 원본을 이동하거나 복제하지 않고 소유 문서로 연결한다.

| 대상 | 정본과 관련 문서 |
| --- | --- |
| 앱·사이트 현재 디자인과 기존 이력 | [디자인 명세](../docs/DESIGN-SPEC.md), [기능 명세](../docs/FEATURE-SPEC.md) |
| 브랜드·라이선스 | [브랜딩](../BRANDING.md), [외부 구성요소 고지](../THIRD_PARTY_NOTICES.md) |
| 패널·설정 상호작용 | [compact panel](../docs/compact-panel-spec.md), [출근 입력](../docs/arrival-inline-controls-spec.md), [수동 근무 유형](../docs/manual-leave-today-spec.md), [설정 탐색](../docs/settings-navigation-check.md) |
| 재질·상태·사용량 | [Liquid Glass](../docs/liquid-glass.md), [휴가 전날](../docs/vacation-eve.md), [AI 사용량 화면](../.impeccable/surfaces/ai-usage.md) |
| 사이트 상세 화면 | [사이트 문서 명세](../docs/site-detail-pages-spec.md), [사이트 개발](../site/README.md) |
| 보존된 제안과 디자인 원본 위치 | 로컬 보존 경로 `docs/design/ollulu/2026-10-19/README.md` (현재 원격 미게시) |

workspace-chanyoung에 있는 [공유 디자인 원본](../../../../디자인/README.md)과 [공통 디자인 진입점](../../../../design/README.md)은 작업공간이 소유한다. 독립 clone에는 해당 경로가 없을 수 있으므로 원본 확인이 필요한 변경은 접근 가능 여부를 기록하고 로컬 제품 자산으로 원본 확인을 대신하지 않는다. 제품에 적용한 런타임 자산은 이 레포가 소유한다.

디자인 변경 절차는 [개발 규칙](../rules/development.md#기능과-디자인-변경), 자동 검증 가능한 동작은 [스펙](../spec/README.md), 기존 수동·격리 QA 구분은 [QA](../docs/QA.md)를 따른다. 시안의 승인, 구현, 자동 렌더, 실제 앱 수락과 공개 사이트 배포는 각각의 상태로 남긴다.
