workspace-chanyoung의 [공용 원본과 기준](../../../../design/common/README.md)은 작업공간이 소유한다. 독립 clone에는 이 경로가 없을 수 있다. 제품별 HTML 미리보기에 필요한 공용 원본 복사본은 `references/shared/`에 두며, 공용 정본의 변경이 제품에 자동 반영되지는 않는다. 제품에 적용한 런타임 자산은 기존 소스 경로에서 관리한다.

디자인 변경 절차는 [개발 규칙](../AGENTS.md), 자동 검증 가능한 동작은 [스펙](../docs/FEATURE-SPEC.md), 기존 수동·격리 QA 구분은 [QA](../docs/QA.md)를 따른다. 시안의 승인, 구현, 자동 렌더, 실제 앱 수락과 공개 사이트 배포는 각각의 상태로 남긴다.

이미지·캡처·PPTX 등 시안 매체는 기존 제외 정책에 따라 로컬에 보관합니다. 이 Git 변경은 목차·규격·미리보기 코드·출처 기록을 포함하며, 새 clone에서 매체까지 복원하거나 화면을 완전히 렌더할 수 있음을 보장하지 않습니다.
