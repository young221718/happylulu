# Mac 1.5.21 배포 범위와 AI 사용량 기준

사용자는 두 신규 Mac 유틸리티의 기본 동작을 수락하고 배포를 요청했다. AI 사용량은 직전 공개 태그 `macos-v1.5.20-build36`의 기능을 유지한다. 설정 디자인·새 유틸리티·플러그인별 설정 위치는 유지하며 Windows는 1.5.13을 보존한다.

## 저장 호환 결정

Astra 사전 검수에서 이전 AI 모델을 그대로 복원하면 다중 프로필 JSON을 옛 5필드로 덮고 Antigravity 실행 파일을 Codex로 실행할 수 있음을 확인했다. 실제 사용자 데이터 대신 합성 fixture에서 원본 손실·잘못된 실행 등 7 assertion 실패를 재현했다.

공개 Codex 모델/UI를 복원하고 `ReleasedUsagePreferences`에서 별도 preferences/history/notification/notificationAccount namespace를 사용한다. 이전 단일 설정 또는 명확히 선택된 Codex 실행 파일·계정 폴더만 가져온다. 다른 공급자·불명확한 선택은 명시적인 실행 파일 선택 전 조회·로그인하지 않는다. 기존 JSON·이력·로그인 파일은 삭제하거나 축소하지 않는다. 손상된 새 저장값은 읽기 전용이며 이전 데이터로 자동 fallback하지 않는다. 계정 폴더 전달은 이전 사용자 연결을 보존하기 위한 호환 코드로 유지한다.

## 검사와 배포

- AI 전체 회귀와 저장 경계 검사를 실행한다. 부분 손상된 유효 JSON도 연결 식별 필드를 검증한다.
- CI 렌더의 옛 일반 설정 토글 3개 기대값을 현재 출근 표시·로그인 2개로 고친다. legacy 탐색 검사는 실제 스크롤 가능 범위를 사용하고 geometry 전달을 기다린다.
- 최종 버전은 1.5.21 build37이다. 깨끗한 검토 commit과 성공한 CI를 배포 소스에 연결하고, 기존 고정 코드 인증서·Sparkle 키로 Universal 패키지와 피드를 만든다.
- 운영 앱을 교체하지 않는 명시적 공개 경로를 사용한다. 이전 자산·서명 피드를 보존하고 새 공개 파일·피드 바이트를 재확인한다. 사용자 기본 동작 수락을 장시간·권한 철회·외부 Mac·실제 업데이트 설치의 완료로 확대하지 않는다.

실행 결과와 공개 링크는 공유 채팅 기록에 남긴다. 원시 로그·패키지·서명 receipt는 Git 밖의 작업 artifact에 보관한다.
