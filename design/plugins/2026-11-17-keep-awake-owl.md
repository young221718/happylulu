# 화면 꺼짐 방지: 부엉이 상태와 제어

2026-11-17 · 이슈 #80 · 로컬 구현 기준 `c88ba88`.

사용 방법과 전원·스크롤의 동작 계약은 [Mac 유틸리티 안내](../../docs/MAC-UTILITIES.md)에 둔다. 이 문서는 화면 꺼짐 방지의 상태 표현·조작·접근성 의도와 검증 범위를 기록한다. 공개 배포, 시각적 수락 또는 실제 하드웨어 검증의 완료 기록은 아니다.

## 상태 부엉이

기존 출퇴근 상태 부엉이는 그대로 두고, 플러그인의 작은 부엉이를 메뉴바에 추가한다. 눈 모양과 상태 글자를 함께 제공해 색만으로 상태를 구분하지 않도록 한다. 메뉴바의 해당 행을 누르면 플러그인 설정이 열리고, 팝오버와 설정 화면의 부엉이 버튼은 요청 자체를 중지하거나 다시 시작한다.

| 상태 | 눈 | 메뉴바 글자 | 패널·설정 상태 글자와 조작 |
| --- | --- | --- | --- |
| macOS 요청 적용 중 | 뜬 눈 | 유지 중 / Awake | 잠자기 방지 요청 적용 중 / Keep-awake request applied. **중지 / Stop**으로 해제한다. 제한 시간이 있으면 남은 시간을 표시한다. |
| 사용자가 중지 | 감은 눈 | 해제됨 / Off | 잠자기 방지 꺼짐 / Keep awake off. **시작 / Start**으로 새 세션을 시작한다. |
| 제한 시간 종료 | 감은 눈 | 해제됨 / Off | 시간 종료 · 해제됨 / Timer ended · released. 자동 재시작하지 않으며 **시작 / Start**으로 재개한다. |
| 생성 또는 상태 읽기 실패 | 감은 눈 | 실패 / Failed | 잠자기 방지 실패 (오류 코드) / Keep-awake failed (code). **시작 / Start**으로 명시적으로 재시도한다. |
| 플러그인 사용 꺼짐·호스트 종료 | 표시 제거 | 표시 제거 | 요청과 타이머를 해제한다. 설정의 부엉이 버튼은 플러그인 사용이 꺼져 있으면 비활성화한다. |

뜬 눈은 macOS assertion 생성에 성공하고 properties의 level이 켜짐으로 읽힌 상태다. 실행 중 약 1초마다 다시 확인한다. 실제 디스플레이가 켜져 있는지, Mac이 모든 조건에서 잠들지 않는지를 측정한 표시가 아니다. 감은 눈도 단독으로 실패를 의미하지 않으므로 중지·만료·실패의 텍스트를 항상 함께 둔다.

내부 중지와 시간 종료는 카탈로그의 플러그인 사용 선택을 끄지 않는다. 사용자는 같은 부엉이 버튼으로 다시 시작할 수 있다. 실제 요청 상태와 설치·사용 선택을 같은 상태로 취급하지 않는다.

## 유지 옵션

- **화면과 시스템:** 화면의 자동 꺼짐과 시스템 idle sleep을 방지하는 요청이다. 이미 꺼진 화면을 깨우는 명령은 아니다.
- **시스템만 · 화면 꺼짐 허용:** 시스템 idle sleep 방지를 요청하며 화면 자동 꺼짐은 허용한다.
- **직접 끌 때까지 / 15분 / 30분 / 1시간 / 2시간:** 제한 시간이 있으면 macOS에도 timeout과 release 동작을 지정한다. 만료 뒤 요청을 자동으로 다시 만들지 않는다.

옵션 선택만으로 기능을 켜지 않는다. 실행 중 옵션 변경은 기존 요청을 해제한 뒤 선택한 범위와 전체 시간으로 다시 시작한다. 앱을 새로 실행할 때도 저장한 시간으로 새 세션을 시작하며 이전 세션의 남은 시간 복원으로 표현하지 않는다. 유지 범위·시간은 보존하고, 사용자 출퇴근·기존 Dev 설정은 변경하지 않는다.

## 덮개 닫힘과 전원 제약

설정에 **덮개 닫힘 동작은 지원 보장 안 됨 · 이 Mac에서 확인하지 않음**을 표시한다. 직접 잠자기·덮개 닫기·배터리 부족·과열에 따른 강제 잠자기를 막는 기능으로 안내하지 않는다. 외장 화면을 쓰는 덮개 닫힘 모드는 Mac 모델과 Apple의 전원·주변기기 조건을 따르며, 이 플러그인의 assertion만으로 지원 여부를 판정하지 않는다.

공식 근거와 모델별 조건은 [사용 안내의 덮개 제약](../../docs/MAC-UTILITIES.md#덮개를-닫을-때의-한계)에 연결한다. 관리자 권한, 시스템의 영구 잠자기 설정 변경 또는 private API 우회는 제공하지 않는다. 배터리 사용량이 늘 수 있다는 설명을 유지한다.

## 사용성과 접근성 검증 범위

코드는 일반 SwiftUI 버튼·선택기를 사용하고, 부엉이 버튼에 현재 상태의 접근성 이름과 시작/재시도 또는 해제의 접근성 힌트를 제공한다. 버튼 안의 장식 이미지는 접근성 트리에서 숨긴다. 메뉴바에도 상태 접근성 이름을 제공하며, 부엉이 이미지는 template로 사용한다. 한국어·영어 문구를 함께 정의한다.

`c88ba88`의 합성 검사는 뜬 눈과 감은 눈의 이미지 데이터 차이, 이름 없는 설정 행 방지, 상태 전이·실패·시간 종료·중지·재시작·옵션 보존과 해제를 확인했다. 이는 실제 렌더 모양이나 보조기술 사용성의 수락을 입증하지 않는다.

다음은 별도 검증이 남아 있다: 최소 설정 폭에서의 긴 한국어·영어 문구와 오류 코드 줄바꿈, 밝고 어두운 메뉴바에서 눈 모양 식별, 1×/2× 렌더, 키보드 초점·버튼/선택기 조작, VoiceOver 상태·행동 안내, 남은 시간의 읽기 부담, 실제 클릭 영역과 패널 높이. 실제 assertion의 전원 효과·장시간/잠자기 이후 타이머·덮개 닫힘도 실물 수락 범위다.

이 문서 후속 작업에서는 코드·테스트·앱을 새로 실행하거나 앱을 등록하지 않았다. 문서 링크와 diff만 확인했다.
