# 시스템 러너: CPU 속도와 메모리 압력색

2026-11-17, 이슈 #79의 로컬 구현 설계. CPU 사용률은 움직임 속도, macOS 메모리 압력은 색으로 전달한다. 메모리 사용량/전체 용량은 수치 정보이며 압력 판정에 쓰지 않는다.

## 표시 결정

| macOS 압력 | 테두리 시작색 → 끝색 | 텍스트 |
| --- | --- | --- |
| 정상 | `#218649` → `#64C987` | 정상 / Normal |
| 주의 | `#D68100` → `#FFBF3F` | 주의 / Warning |
| 위험 | `#D63C3C` → `#FF7971` | 위험 / Critical |
| 없음·읽기 실패 | `#7D8590` → `#A6ACB5` | 미측정 / Unavailable |

부엉이 눈 모양은 고정하고 테두리만 기존 CPU 정책으로 회전한다. 동물 모드에서는 기존 동물 템플릿을 그대로 달리게 하고 부엉이 테두리에 정지한 압력색을 표시한다. 이 방식은 동물을 직접 채색해 합성 메뉴바 이미지를 비템플릿으로 만드는 경우의 밝음·어두움 대비 변경을 피하며, 추가 상태 항목이나 호스트 API 없이 두 모드에서 압력을 보인다.

요약은 기존 332×172pt 안에서 상단 오른쪽에 메모리 상태 색점을 두고 용량 행의 중복 압력 문구를 제거한다. 설정은 기존 3열 구조를 유지하고 색상 선택 행을 4상태 범례 한 행으로 바꾼다. 임의 색상과 압력색이 혼동되지 않게 고정 의미를 사용한다. 기존 저장 색상은 삭제·덮어쓰기 없이 보존한다.

색만으로 상태를 설명하지 않는다. 요약·설정에 상태 이름을 표시하고 두 메뉴바 모드의 접근성 이름에도 CPU와 메모리 압력 상태를 제공한다. 미측정은 회색과 명시적인 이름으로 유지하며 용량만 읽혀도 정상으로 추정하지 않는다.

## 움직임·자원 경계

압력은 기존 1초 표본으로 갱신한다. 색이 바뀌어도 CPU 속도·회전 위상·애니메이션 타이머를 초기화하지 않으며 깜빡임·펄스·추가 타이머를 만들지 않는다. 기존 CPU 속도와 24/12fps 눈빛·16/4fps 동물 상한, 동작 줄이기, 잠자기·깨우기 세대 검사, 중지 정리와 배터리 5초 캐시는 유지한다. 동작 줄이기는 움직임만 멈추며 현재 압력색과 상태 이름은 유지한다.

외부 통신·권한·개인 설정·출퇴근 데이터·프로덕션/Dev 앱 등록을 바꾸지 않는다. 합성 타이머·지표와 등록 없는 렌더만 검사한다. 실제 VoiceOver, 잠자기·배터리 소모, 메뉴바의 사용자 외형 수락은 별도 확인이다.

## 검증

- 먼저 새 합성 회귀가 기존 구현에서 정상 압력의 고정 녹색 메뉴바 표시 부재로 실패하는 것을 확인했다.
- CPU 값이 일정한 동안 주의·위험·정상·미측정 전환이 압력색과 접근성 텍스트만 바꾸고 타이머·호스트 일정 알림을 건드리지 않는지 검사한다. 용량 1 byte의 위험과 100% 사용량의 정상을 써서 압력/사용률 혼동을 검출한다.
- 동물 모드의 템플릿 이미지+정지 테두리, 동작 줄이기, 잠자기 출력 정리와 기존 사용자 색상 보존을 검사한다.
- 한국어/영어·밝음/어두움 설정 16개, 정상/주의/위험/압력 미측정/전체 미측정 요약 20개를 실제 SwiftUI 뷰로 렌더한다. 자동 검사와 이미지 확인은 실행 결과로 별도 기록하며, 실제 메뉴바 사용자 수락을 뜻하지 않는다.

2026-11-17 작성자 검증: `CPURunnerChecks`, `SystemMetricsChecks`, `AfterSixChecks` 통과. `swift test --build-system native --jobs 2`의 XCTest 59개와 Swift Testing 기본 8개 통과, 실제 IOKit assertion 검사 1개는 기존 기본 정책에 따라 실행하지 않았다. 설정 16개·요약 20개 렌더 후 영어의 긴 미측정 문구와 제목/압력 배지 정렬을 이미지로 확인했다. 새 압력 회귀는 비영(0이 아닌) 회전 위상 유지도 검사한다.

제한된 작업 환경에서는 작업 `.build` 안에 모듈/SwiftPM 캐시를 두고 이미 존재하는 Sparkle 2.10.0 checkout과 artifact를 복사해 사용했다. 외부 다운로드·설치·앱 실행 없이 검사했으며 `--disable-sandbox`, `--skip-update`와 로컬 cache/config/security 경로를 지정했다. 이 옵션의 SwiftPM deprecation 경고와 실제 메뉴바/VoiceOver·배터리·잠자기 실기 확인 공백은 남는다. 통합과 독립 리뷰는 상위 작업에서 수행한다.
