# 플러그인 개선 화면 규칙

2026-11-17 Mac 개발 소스의 플러그인 개선에서 적용할 화면 규칙이다.
공개 배포나 사용자 실기기 수락을 뜻하지 않는다.

## 다우: 근태 변경 제안

- 다우 설정에서 기존 값과 회사에서 읽은 오늘의 값을 비교하고 사용자가 반영하거나 유지할 수 있다. 자동 반영은 휴가와 출근 시각을 각각 명시적으로 켠다.
- 제안이 있으면 메뉴 패널에서 다우 설정으로 이동할 수 있게 하며, 제안 행을 위한 높이를 패널과 호스트가 같은 기준으로 계산한다.
- 누락·오류·오래된 값은 확인된 출근이나 휴가 없음으로 표현하지 않는다. 수동 기록과 충돌하면 덮어쓰지 않고 확인한다.
- 로컬 알림은 사용자의 명시적인 권한 선택을 따르고, 잠금 화면 등에 개인 근태 수치를 노출하지 않는다.

## 캘린더: 중복 표시

- 복사된 일정은 오늘 목록과 월별 화면에서 한 번 표시하되 연결된 출처를 확인할 수 있어야 한다.
- 원본 일정과 동기화 데이터는 수정하지 않는다. 반복 회차·다른 내용·시간대와 종일 경계를 구분하며, 정확히 동일한 독립 일정은 구분하기 어려울 수 있다. [판별 규칙](../../docs/calendar-display.md)

## AI 사용량: 제공자와 연결

- 기존 Codex 연결은 그대로 유지하고 추가 프로필을 사용자가 명시적으로 선택한다.
- Claude·Antigravity의 파일 기반 연결은 마지막 관측과 현재 조회를 구분한다. 새 관측이 없거나 한도가 없으면 이전 수치를 현재 값으로 표현하지 않는다.
- 공급자마다 지원하지 않는 계정 식별·이력·알림을 추정하지 않는다. [연결 범위](../../docs/AI-MODEL-USAGE.md)

시스템 러너의 속도·압력색은 [시스템 러너 규칙](2026-11-17-system-runner-pressure.md), 화면 켜짐 유지 부엉이는 [부엉이 규칙](2026-11-17-keep-awake-owl.md)을 따른다. 자동 검사와 사용자 시각·실기기 수락은 구분한다.
