## 검증 및 한계

`CPURunnerChecks`의 CPU, 설정, 동물 수명주기, 부엉이 회전, 메뉴바 통합, 시스템 측정 6개 검사 그룹이 통과했다. `scripts/check-owl-orbit.sh`의 렌더 검사 20,343개와 `scripts/check-ai-usage-ui.sh` 네이티브 화면 검사가 통과했다. 원본 알파와 표정 보존, 밝고 어두운 외관, 선택 강조, 루프·캐시 범위, 타이머 정지 동작을 검사했다.

메뉴바 외관 알림이 다시 그리기를 반복하던 결함도 수정했다. 최종 무애니메이션 진단에서는 외관 알림 23회에 렌더 5회로 유지됐고, 각 100ms 대기 구간의 반복 렌더가 없었다. 첫 48프레임 생성은 평균 2.440ms, 최대 26.330ms였다. 최종 Debug 및 Release 앱 빌드와 서명 검증이 통과했다. 두 독립 코드 검토에서 추가 수정이 필요한 결함은 발견되지 않았다.

설치본 화면 확인 도구가 시간 초과되어 실제 마우스를 누른 채 끌어 취소하는 동작과 사용자 화면의 최종 선택 배경은 미검증이다. macOS 13 실기기 검증, Sparkle 자동 업데이트 전체 경로, Apple 공증은 하지 않았다. 전체 XCTest는 기존 환경의 `no such module 'XCTest'` 오류로 실행하지 못했으며, 위 실행형 검사와 네이티브 검증을 구분한다.
