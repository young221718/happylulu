- [한영 브라우저 12조건](cool-browser-qa.json)
- 48페이지 정적 검사 통과. HTML은 캐시 키 외 동일하며 이미지·JavaScript·다운로드·본문·ID·CSS 배치를 보존했다.
- 한영 홈·기능·가이드의 1280/320px에서 흰 배경·소문자·가로 넘침 없음을 확인했다. 대표 텍스트 대비 12쌍의 최소값은 5.31:1이다.

- [교정 후 실제 로컬 첫 화면](lowercase-desktop.jpg)
- [브라우저 8조건 확인 기록](lowercase-browser-qa.json)
- 기존 48페이지·링크·다운로드·앵커 검사, 상태·메뉴·가이드 3그룹 검사, 앱 빌드와 가상 데이터 렌더 통과. 소문자 회귀 검사는 교정 전 실패·교정 후 통과 확인.

- 로컬만 적용. 이번 교정에서 설치 앱 교체·commit·push·공개 배포는 하지 않음.

## 적용

오프화이트·라일락·보라색과 부엉이 브랜드, 구체적인 홈 제목과 새 Mac 패널 예시, 플랫폼별 다운로드 안내, 기능 소개 12개의 목적별 묶음, 가이드 목차 11개의 접기·펼치기, 8가지 상태 표정 체험을 적용했다. 기존 마지막 금요일 비교도 유지했다. 기능 제거는 없다.

웹 데모는 고정된 가상 데이터만 사용한다. 오전반차는 13:00–17:00, 오후반차는 09:00–13:00이다. 룰루데이는 단축근무이고 예정 시각 경과는 실제 퇴근 기록이 아니다. 새 화면은 로컬 Mac build34.5 미리보기로 표시하며 현재 공개 Mac1.5.18 build34·Windows1.5.13 다운로드와 구분한다.

## 확인한 범위

- 기존 검사 `python3 site/check-site.py` 통과: 48개 경로·한영·12개 기능·다운로드·라이선스·과거 릴리즈 본문 10개 보존.
- `node --check site/dist/app.js`, `node site/tests/interactions.cjs`, `git diff --check -- site` 통과. 의미 있는 이벤트 검사 3그룹이며 브라우저를 대신하는 검사는 아니다.
- 로컬 HTTP 응답 200 확인. CUA 브라우저에서 한국어·영어 주요 경로 13개 × 1280/390/320px = 39개 화면의 제목과 가로 넘침 검사 통과.
- 홈·가이드·기능 목록을 649/650/651, 719/720/721, 799/800/801, 899/900/901px에서 추가 확인했다. 36개 경우에서 가로 넘침이 없었다. 합계 75개이며 모든 화면의 모든 요소를 시각 검증했다는 뜻은 아니다.
- 한영 각각 8상태의 이미지·대체 텍스트·제목·시간, 라디오 방향키 조작, 모바일 메뉴 Escape와 포커스 복귀, 가이드 목차 링크 선택·목적지·Escape, 기능 선택 메뉴의 12항목과 현재 위치, 기존 금요일 비교를 실제 브라우저에서 확인했다.
- 독립 읽기 전용 검토에서 조치가 필요한 결함이 없었다. 기존 파일 경로·ID·외부 링크, 호스팅 설정·원본 시계 이미지 바이트와 승인 패널 원본을 대조했다. 대표 텍스트 색 대비는 4.86–5.87:1이다.

검토 중 오전반차 예시의 5시간 오류를 실패하는 회귀 검사로 확인한 뒤 4시간으로 바로잡았다. 새 CSS/JS가 이전 캐시와 섞이는 문제는 모든 페이지의 자산 버전 키를 바꿔 해결했다.

## 위치와 한계

소유 checkout은 `app/happylulu/design-refresh-local`, branch `cy-agent/design-refresh-local`, HEAD `8a4a5380f4fd8b55848cd2e5357296dbdcc35a5c`이며 로컬 미커밋 상태다. [사이트 README](../../../../../design-refresh-local/site/README.md), [구현 계획](../../../../../design-refresh-local/docs/plans/2026-10-21-site-refresh-local.md)을 따른다. 앱 코드와 설치 앱은 이번 사이트 작업에서 변경하지 않았다.

실제 VoiceOver 알림과 JavaScript를 끈 브라우저는 시험하지 않았다. JavaScript 없는 탐색은 기본 HTML과 CSS 구조로 검토했다. 원격 CI·공개 다운로드 HTTP·공개 배포·앱 설치는 실행하지 않았다. 기존 호스팅 checkout의 과거 다운로드/업데이트 피드는 이번 로컬 소스에 없으며 변경하지 않았다.

미리보기 서버는 이 Mac의 `127.0.0.1:8765`에만 열려 있다. 서버가 종료됐을 때는 소유 checkout에서 `python3 -m http.server 8765 --bind 127.0.0.1 --directory site/dist`로 다시 실행할 수 있다.

사용자 피드백으로 한영 홈 제목 위에 기존 전신 올루루를 추가했다. [데스크톱 최신 화면](hero-owl-desktop.jpg), [모바일 최신 화면](hero-owl-mobile.jpg), [브라우저 확인 기록](hero-owl-qa.json)을 별도로 보존한다. 이보다 위의 기존 화면은 첫 구현 이력이다.

원본 `디자인/올루루/assets/올루루-기본.png`를 변형 없이 사이트 자산 `happylulu-mascot.png`로 복사했다. 실제 Mac 패널·다운로드·기능을 유지했다. 사이트 48페이지 검사와 변경 파일 공백 검사가 통과했다. 브라우저에서 한영 데스크톱 1033px, 한영 320px, 한국어 390px의 총 5조건에서 이미지 로드·첫 화면 노출·가로 넘침 없음·앱 패널 보존을 확인했다. 공개 배포는 수행하지 않았다.
