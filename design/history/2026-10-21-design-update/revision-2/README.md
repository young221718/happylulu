# happylulu 2차 디자인 수정안

2026년 10월 21일 피드백: 1차 제안의 색감을 다시 잡고, 올루루 캐릭터 원형과 일치하는 눈을 기준으로 출근·퇴근 예정 시각·룰루데이·반차에 따른 표정 차이를 만든다. 이 자료는 색감과 캐릭터 디테일을 고르는 수정 제안이다. 기존 [1차 제안서](../README.md)의 기능 범위를 유지한다.

색감 보드의 생성 원본에는 제품 기능을 부정확하게 설명한 문구가 있었다. 전달 PPT와 위 미리보기에서는 출근 기록·퇴근 예정 시각으로 바로잡았다. 원생성 그림은 연구 이력이며 외부 전달에는 교정된 PPT와 미리보기를 사용한다.

## 이번에 고칠 점

- 화면 전체에 넓게 깔린 회녹색을 줄인다. 밝은 중립 바탕, 흰 카드, 짙은 글자에 올루루 보라색을 선택·강조에 사용한다.
- 기존 v3 심볼은 원본을 그대로 추출한 눈이 아니다. 둥근 대칭 눈테와 수직 동공, 검정 물방울 부리가 원형의 인상과 다르다.
- [올루루 원본](../../../references/shared/ollulu/assets/올루루-기본.png)의 깊은 V자 크림색 얼굴 면, 큰 타원 동공, 기울기와 부리 위치를 하나의 기준 형태로 삼는다. 표정마다 눈 간격·얼굴 면·부리를 새로 그리지 않는다.
- 사용자 피드백에 따라 v3의 형태와 1차 민트 중심 권장안을 다시 검토한다. 기존 파일과 과거 선택 기록은 보존한다.

## 색감 비교

| 역할 | A. 오프화이트·라일락 — 권장 | B. 크림·플럼 |
| --- | --- | --- |
| 화면 바탕 | `#FAF9FC` | `#FFFBF5` |
| 카드 | `#FFFFFF` | `#FFFFFF` |
| 본문·숫자 | `#2F2B3D` | `#352F3D` |
| 선택·주요 버튼 | `#7054B3` | `#7659A6` |
| 보조 면·장식 | 라일락 `#EEE8F8` | 앰버 `#E8AD47` 소량 |

두 팔레트는 캐릭터와 어울리도록 새로 제안한 값이다. 이미지에서 정확히 추출한 색이나 확정된 제품 토큰이 아니다. A는 정보가 많은 작은 앱 화면에, B는 따뜻한 캐릭터 소개 표현에 적합하다. 기존 사용자의 5개 테마·개별 색상 설정을 덮어쓰지 않는다. 앰버는 흰 바탕의 작은 글자로 사용하지 않는다.

## 같은 눈에서 나오는 상태별 표정

| 상태 | 표정 방향 | 반드시 함께 보이는 의미 |
| --- | --- | --- |
| 출근 대기 | 원본 기본 눈, 중립 시선 | 출근 기록 없음 |
| 일반근무·예정 시각 전 | 또렷하게 뜬 눈 | 일반근무와 남은 시간 |
| 룰루데이·예정 시각 전 | 살짝 올라간 눈웃음 | 단축근무인 룰루데이와 남은 시간 |
| 오전반차 | 한쪽을 가볍게 감은 눈 A | 오전반차: 오전에 쉬고 오후 출근 |
| 오후반차 | 반대쪽을 가볍게 감은 눈 B | 오후반차: 오전 출근 후 오후에 쉼 |
| 예정 퇴근 시각 경과 | 편안한 웃는 눈 | 예정 시각 경과; 실제 퇴근 완료가 아님 |
| 연차·공가 | 양쪽을 편히 감은 눈 | 연차·공가; 기존 출근 기록 보존 |
| 오늘 쉬는 날 | 편안한 반쯤 감은 눈 | 사용자가 지정한 쉬는 날; 주말 자동 판정이 아님 |

표정은 상태를 보조한다. 좌우 윙크만으로 오전·오후를 이해해야 하는 설계를 피하고, 시간·유형 문구를 유지한다. 출근과 휴가를 화남·슬픔으로 평가하지 않는다. 예정 시각 경과 후에도 근무 유형은 보조 라벨로 남긴다.

표시 우선순위 제안은 **연차·공가 → 오늘 쉬는 날 → 출근 대기 → 예정 퇴근 시각 경과 → 근무 유형별 눈**이다. 현재 앱의 계산·기록 정책은 바꾸지 않는다. 오전·오후반차는 모두 출근부터 4시간이며 룰루데이 단축을 중복 적용하지 않는다. 오늘 쉬는 날의 확인·기록 삭제 계약도 기존 기능 명세를 따른다.

## 원형 충실도와 소형 표현

생성된 그림은 원본을 참조한 재구성 시안이다. 픽셀 단위 추출·정확한 트레이싱·최종 벡터 제작이 끝난 자산으로 간주하지 않는다. 실제 적용 전에는 원본 위에 기준 도형을 겹쳐 눈 주변 면, 동공 중심·크기·기울기, 부리 위치를 확인해야 한다. 원본의 약간 돌아본 각도를 정면으로 바꿀 때의 보정도 명시한다.

메뉴바는 18 pt 단색에서 눈 주변 형태·동공·부리를 우선한다. 패널과 웹에서는 크림·라벤더·주황의 캐릭터 색을 쓸 수 있다. 작은 반짝임은 1×에서 뭉치면 줄이고, 표정 구분이 어려우면 표정 수를 줄이거나 문구를 강화한다. 밝고 어두운 메뉴바의 1×·2× 실기 검증은 아직 수행하지 않았다.

현재 [8개 상태의 눈 방향 시안](visuals/owl-eight-state-direction-board-v2.png)은 상태 대응을 비교하는 연구 그림이다. 단색의 룰루데이·예정 시각 경과·연차/공가가 비슷한 웃는 눈을 공유하므로 8가지가 모두 구분되는 완성 심볼로 쓰지 않는다. 이 세 상태의 구분, 쉬는 날의 중립적인 표정, 원형과 다른 대칭 윤곽·부리는 추가 정교화가 필요하다. 이전 생성 그림도 연구 이력으로 보존한다.

웹의 눈 표정은 기능 소개와 명시적인 시연에 사용한다. 방문자의 실제 출근 상태를 아는 것처럼 표시하지 않는다. 앱과 사이트의 표정 원본은 공유하되 크기·색상·애니메이션은 각 화면의 목적에 맞춘다.

## 생성 기록과 검증 범위

이미지 시안은 기본 내장 ImageGen으로 만들었다. [첫 눈 보드 요청문](visuals/initial-eye-board-prompt.txt), [색감 비교 요청문](visuals/palette-comparison-prompt.txt), [눈 보드 보정 요청문](visuals/eye-board-refinement-prompt.txt)을 보존한다. 최종 전달은 기능 문구를 교정한 PPT와 렌더링 미리보기다.

앱 5장과 사이트 4장을 개별 렌더링해 확인했다. 파일 구조·배치·재가져오기를 검사했으며, [후보 색상 대비 계산](palette-contrast.json)은 정적 색상쌍 검사다. 실제 앱·PowerPoint 실앱·18 pt 메뉴바의 표시 검증을 대신하지 않는다. 본문 글꼴은 Apple SD Gothic Neo이며 다른 운영체제에서는 대체될 수 있다.

이 수정안은 디자인 검토용이다. 제품 코드·설치 앱·릴리즈·사이트 배포를 변경하지 않는다.
