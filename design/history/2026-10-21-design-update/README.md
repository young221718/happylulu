# happylulu 디자인 업데이트 제안

**최신 로컬 적용본:** 첨부 표에 맞춘 8상태 메뉴바 눈과 패널 좌상단 컬러 부엉이를 동기화하고, 중복된 근무유형 설명을 제거했다. Dock 기본 아이콘도 선택한 전체 캐릭터다. [build 34.5 화면·원본·제작 기록·검증 결과](state-assets/README.md). [build 34.2 기록](local-app-header-update/README.md)과 아래 PPT·기준 설명은 당시 이력으로 보존한다.

**최신 사이트 제안:** ChatGPT Sites 유지 방향에 맞춘 [사이트 개선안 3차 · PPT 6장과 화면 시안](site-revision-3/README.md). 승인된 부엉이·보라색, 앱의 역할이 드러나는 첫 화면, 플랫폼별 다운로드, 기능 탐색과 모바일 목차, 8상태 가상 데모를 제안한다. 기존 기능·경로를 보존하며 실제 사이트와 공개 릴리즈는 변경하지 않았다.

**사이트 로컬 적용:** 이후 사용자 승인으로 위 3차안을 로컬 사이트에 구현했다. [실제 화면·로컬 URL·검증 범위](local-site/README.md). 공개 사이트·릴리즈는 변경하지 않았다.

기존 기능을 보존하면서 앱과 소개 사이트의 디자인을 검토하기 위한 2026년 10월 21일 제안이다. 현재 기능과 과거 제거·이동, 앞으로 적용할 변경을 구분한다. 화면 콘셉트는 구현 완료 화면이 아니며 최종 동작은 아래 명세서를 따른다.

**제안 검토 이력:** 색감·원형 눈·근무 상태별 표정에 대한 사용자 피드백은 [2차 디자인 수정안](revision-2/README.md)에 반영했다. 이후 승인된 A 색감과 최신 첨부 표의 로컬 적용 결과는 위 34.5 자료를 따른다. 아래 1차 PPT와 기존 v3 선택 기록은 보존한다.

## 최초 제안 당시 기준과 결정

- 로컬 소스는 `main`의 `c44cdb8`이다. 원격에서 병합된 [PR 53](https://github.com/young221718/happylulu/pull/53)의 외관 전환·사이드바 클릭 개선을 별도 반영한다. 병합 commit은 `8a4a538`이며 이 문서 작업에서 로컬 baseline을 변경하지 않았다.
- [PR 54](https://github.com/young221718/happylulu/pull/54)의 표준 편집 명령 복구는 Draft다. 실제 활성 창의 붙여넣기 수락은 완료로 처리하지 않는다.
- [이슈 52](https://github.com/young221718/happylulu/issues/52)의 확정 범위는 메뉴바 눈·부리 심볼이다. [기존 선택 기록](../../branding/selection/README.md)의 올루루·시계 PNG와 현행 런타임 앱 아이콘이 다르므로, 이번 제안서의 브랜드 참조를 앱 아이콘 교체 승인으로 해석하지 않는다.
- 기능 제거 제안은 자동 승인되지 않는다. 진행 막대 복원 등 검토 항목은 기능 명세서에서 상태와 수락 기준을 확인한다.

최초 문서·디자인 제안 단계에는 제품 소스 변경과 설치가 포함되지 않았다. 이후 사용자 승인에 따른 Mac 로컬 구현·설치는 위 버전별 기록에 구분한다. 릴리즈·사이트 배포는 수행하지 않았다. 기존 디자인 원본은 보존한다.

## 파일 검증

앱·사이트 PPT는 각각 8장이다. 총 16장을 이미지로 렌더링해 개별 검토했고, 파일 구조·슬라이드 배치 검사와 재가져오기를 통과했다. 각 PPT의 표 3개는 편집 가능한 표다. 화면 콘셉트 이미지는 기능 명세를 대체하지 않는다.

PPT 본문 글꼴은 Apple SD Gothic Neo이며 폰트를 파일에 포함하지 않았다. 다른 운영체제에서는 대체 글꼴로 보일 수 있으므로 고정된 미리보기 PNG도 함께 제공한다. PowerPoint 실앱에서의 열기와 제품 앱·사이트의 실행 검증은 수행하지 않았다.
