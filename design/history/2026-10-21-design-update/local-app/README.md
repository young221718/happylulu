## 검증 결과와 한계

Core·공통 계산20건·외관/Retina·3시간대 패널 입력·붙여넣기·프로필 격리·설정28클릭·한영 렌더·arm64 빌드가 통과했다. 독립 코드 검토와 설치본의 기존 인증서/엄격한 서명·번들 바이트 일치·새 프로세스 실행을 확인했다.

재실행 후 출근/플러그인 파일, 일반 설정, 캘린더 DB/WAL, 사용자 아이콘과 이미지가 보존됐다. SQLite 공유 메모리 파일은 DB를 여는 동안 바뀌었으며 실제 DB/WAL은 같았다. 로컬 번들의 자동 업데이트 서비스는 꺼 두었다. 기존 앱과 외관/데이터 복구본은 Git 밖에 보관했다.

실제 데스크톱 메뉴 클릭·VoiceOver·잠금해제/재부팅·Windows·원격 CI는 미검증이다. 화면 제어 도구가 연결 실패해서 로컬 렌더링과 프로세스 실행 증거를 분리했다. 사이트 디자인은 제안서 상태다.
