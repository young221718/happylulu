# HappyLulu 사이트 개선 제안

2026년 10월 21일. 사용자가 선택한 ChatGPT Sites 운영 방향을 기준으로, 최신 로컬 앱 디자인과 사이트를 연결하는 검토용 제안이다. **승인 전 제안이며 제품 코드·공개 사이트·릴리즈를 변경하지 않았다.** 기존 [1차 제안](../README.md)과 [2차 색감 제안](../revision-2/README.md)은 이력으로 보존한다.

## 제안 내용

| 순서 | 제안 | 판단 기준 |
| --- | --- | --- |
| P0 | 앱과 같은 부엉이, 오프화이트·라일락·보라색 | 기존 앱과 사이트가 같은 제품으로 보이는가 |
| P0 | ‘출근 기록과 퇴근 예정, 한눈에.’ 제목과 새 Mac 화면 | 앱의 역할과 지원 플랫폼을 첫 화면에서 이해하는가 |
| P0 | OS별 다운로드 버튼, 버전·OS·런타임·설치 안내를 같은 카드에 표시 | 설치 파일과 설치 조건을 함께 찾는가 |
| P1 | 기존 기능 12개를 목적별로 묶고 상세 링크 유지 | 기능을 빠뜨리지 않고 찾기 쉬워지는가 |
| P1 | 모바일 가이드 목차 11개 접기·펼치기 | 긴 문서에서 현재 위치와 다음 항목을 찾는가 |
| P2 | 8개 상태를 직접 고르는 가상 부엉이 데모 | 실제 근무 기록을 읽는다는 오해 없이 표정과 의미를 이해하는가 |

기존 브랜드 문구 ‘작은 번거로움은 덜고, 내 일에 집중.’는 보조 소개에 유지한다. Mac과 Windows의 지원 범위를 분리하고, 새 Mac 전용 화면을 Windows 기능처럼 소개하지 않는다. 모바일 시안은 반응형 웹이며 모바일 앱 출시를 뜻하지 않는다.

현재 공개 버전 표기는 Mac 1.5.18 build 34, Windows 1.5.13을 기준으로 했다. 새 디자인의 공개 릴리즈 번호와 일정은 정하지 않았다. 앱 화면에는 ‘디자인 제안·가상 데이터’를 표시한다.

## 유지·변경·추가

- **유지:** 기존 기능 12개, KO/EN 48개 HTML 경로, 사용 가이드, 릴리즈와 과거 설명, 다운로드·업데이트 피드, 개인 사용 무료·비상업 라이선스. 기능 삭제 제안은 0개다.
- **변경:** 브랜드 색과 캐릭터, 홈의 제목·화면 모형, 플랫폼별 다운로드 위계, 기능 탐색 묶음과 모바일 목차.
- **추가:** 현재 데모를 8상태 선택 시연으로 확장하는 제안. 방문자의 기록·캘린더·근무 상태를 읽지 않고 고정된 가상 시간만 사용한다.

룰루데이는 단축근무이며 휴일로 표현하지 않는다. 마지막 금요일 2시간 단축과 반차 중복 적용 없음의 기존 설명을 유지한다. 예정 시각 경과는 실제 퇴근 기록을 뜻하지 않는다. 일반근무·반차·연차의 기존 계산과 기록 계약을 바꾸지 않는다.

홈에는 ‘출근 기록은 내 컴퓨터에 저장하고, 선택한 외부 연동만 해당 서비스와 통신합니다.’라는 안내를 제안한다. 방문자 분석 자료가 없으므로 전환율 등 효과 수치는 주장하지 않는다.

PPT 제목·본문·웹 시안·비교표는 편집 가능한 텍스트·도형·표다. 부엉이와 앱 화면은 기존 PNG를 원래 비율로 배치했다. 자세한 근거와 제안 범위는 각 장의 발표자 노트에 남겼다.

## 검증과 한계

`@oai/artifact-tool`로 PPTX를 만들고 최종 파일을 다시 가져와 6장을 개별 렌더링했다. 구조 검사, 16:9 슬라이드 크기, 한글 글꼴, 제목 배치, 편집 가능한 비교표 2개, 재가져오기 검사를 통과했다. 최종 6장과 수정한 다운로드 화면을 직접 확인했다. 전체 미리보기와 별도 시안 PNG는 최종 PPT 렌더에서 추출했다.

이 검사는 실제 PowerPoint·브라우저의 동작 검사, 320px·390px 웹 구현 검사, 키보드 탐색·대비의 전체 검증을 대신하지 않는다. 구현 후에는 기존 `site/check-site.py` 및 경로·한영·기능·다운로드 보존 검사와 화면 확인이 필요하다. 원격 게시와 설치 파일 변경은 수행하지 않았다.

[최종 결과 해시](manifest.json). 글꼴은 Apple SD Gothic Neo이며 다른 운영체제에서는 대체될 수 있다.
