## 최종 로컬 검증 · 2026-10-22

- `runner-system-monitor`의 main `f111c37` 기반 미커밋 변경. 소스 328개 파일의 해시를 빌드 전후 및 설치 직전에 대조했다.
- 최종 release 빌드·고정 인증서 서명·서명 검증 통과. 로컬 1.5.19/build35.4를 설치·재실행했고 후보 번들 전체 일치와 기존 앱 백업을 확인했다.
- 출퇴근 기록·캘린더 연결·외관·사용자 설정·캘린더 권한 보존 검사 통과. 이전 활성화 설정을 유지해 시스템 러너는 꺼진 상태다.
- CPURunnerChecks 5개 묶음, SystemMetricsChecks 및 이 Mac의 실제 수치 조회, 아트워크 220개 검사, 플러그인 구조 검사, AfterSixChecks 33개와 관련 추가 검사 통과.
- Codex 표시 방식·설정 보존·아이콘 부재/손상 대체 표시·실제 Codex 아이콘 출처를 독립 실행 검사로 검증했다. 전체 XCTest는 현재 Command Line Tools 환경에서 `no such module 'XCTest'`로 실행하지 못했다.
- 네이티브 통합 화면 18개: 출퇴근·5개 시스템 항목·Codex 아이콘, 밝음/어두움 설정과 NSStatusBarButton. 화면의 숫자와 출퇴근 시각은 합성 검사값이다.
- 패키지의 RunCat 리소스를 임시 앱으로 옮겨 원래 `.build` 읽기를 차단하고, 고양이 5프레임 렌더가 기대 이미지와 바이트 단위로 일치함을 확인했다.
- 독립 검토에서 찾은 네트워크 링크 상태 조회 실패 오표시를 수정했고 재검토에서 해소했다. 실패·첫 샘플·재연결을 실제 0과 구분한다.
- macOS가 그리는 선택 상태 배경은 버튼 캡처에 포함되지 않아 선택 배경 대비는 미검증이다. macOS13 실기기, 잠금/재부팅, 사용자 디자인 수락도 미검증이다. 설치 후 네이티브 조작 도구 연결이 끊겨 실제 설치본의 추가 클릭 검증은 진행하지 못했다.
- 이 단계에서는 커밋·PR·머지·공개 릴리즈·사이트 배포를 하지 않았다.
