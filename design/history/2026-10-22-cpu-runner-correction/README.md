# CPU 러너 시안 충실도 수정

이 폴더는 v4 / 로컬 빌드 35.2의 당시 결과입니다. 이후 사용자가 원안과 여전히 다르고 완성도가 부족하다며 거부했습니다. 아래 독립 검토 결과는 당시 판단으로 보존하며 사용자 디자인 수락을 뜻하지 않습니다. 사용자 요청에 따른 [Astra 재작업 결과](../2026-10-22-cpu-runner-astra/README.md)는 별도 보존하며, 후속 비교 화면은 사용자가 수락하고 PR 게시를 요청했습니다.

2026-10-22 사용자가 최초 구현의 프레임이 제안과 크게 다르다고 지적해 수정한 실제 AppKit 렌더입니다. 새로운 제안 이미지가 아니라 앱의 `RunnerArtwork`가 생성하는 3종×8프레임입니다.

## 비교 기준

- [원본 제안](../2026-10-22-cpu-runner-concepts/runner-candidates-v1.png)의 아래쪽 단색 캐릭터가 기준입니다. 원본 파일은 그대로 보존했습니다.
- [최초 구현](../2026-10-22-cpu-runner-preview/README.md)은 비교용으로 보존합니다. 자동 검사 통과와 디자인 수락은 별개입니다.
- 큰 머리·통통한 몸·짧은 둥근 발, 햄스터의 큰 둥근 귀, 토끼의 길고 둥근 귀, 고양이의 열린 갈고리 꼬리를 보정했습니다.

## 검증과 한계

최종 아트워크 250개 assertion, CPU·선택 저장·수명주기 회귀 검사, 3종×한국어/영어×밝음/어두움 설정 12개 렌더, 앱 빌드와 서명 검증을 통과했습니다. 독립 정적 시각 검토에서 26×18pt에 맞춘 범위 안에서 중대한 캐릭터 정체성 이탈을 추가로 찾지 못했습니다.

원안과 픽셀 단위로 같지는 않습니다. 토끼 귀는 조금 더 납작하고, 햄스터 배와 고양이 수염·발 안쪽 세부는 작은 크기에 맞춰 단순화했습니다. 독립 검토는 실제 사용자 디자인 수락이나 마우스·키보드·VoiceOver 수락을 대신하지 않습니다.
