# 설정 디테일 개선 적용

2026-11-14. 사용자가 [Apple 설정 비교 분석](2026-11-14-apple-settings-detail-audit.md)의 반영을 승인했다. 해당 분석은 당시 상태와 제안의 이력으로 유지하고, 현재 규칙은 [README](README.md)에서 관리한다. 소유 체크아웃은 `issues-dev-20261109`, branch `mac/dev`, 기준 HEAD는 `947e59681b19102fed8d2a9ed339e5494c5dd910`이다.

## 반영 내용

- 파란 사이드바 문양을 15pt medium에서 13pt regular·medium scale로 조정하고 20pt 슬롯과 클릭 영역을 유지한다.
- 실제 Dev에서 목록이 포커스를 잃었을 때 회색 선택 배경에 흰 글자가 남는 기존 대비 문제를 재현했다. 목록 포커스를 관찰해 활성 선택만 흰색, 비활성 선택은 시스템 글자색과 파란 문양으로 표시한다. 포커스나 키보드 순서를 강제하지 않는다.
- 상단 15pt semibold, 구역 13pt medium, 항목 13pt regular, 설명 11pt regular로 위계를 정리한다. 공통 값은 `SettingsStyle.swift`에서 관리한다.
- 구역 간 24pt는 유지하고 제목→카드는 10pt, 공통 행 좌우는 14pt·상하는 12pt로 맞춘다. 일반·업데이트·근무 시간·플러그인 사용 설정은 같은 행 구성과 오른쪽 조작 정렬을 사용한다.
- 일반은 `사용 환경`과 `업데이트`로 구분한다. 언어의 인사 예시를 제거하고 버전을 카드 안으로 옮긴다. 남은 시간 계산 안내는 펼칠 수 있게 한다.
- 근무는 `오늘 근무`·`근무 시간`·`출근 기록`으로 구분한다. 근무 유형 애니메이션, 출근 수정과 조건부 안내, 근무·휴게 범위와 증분, 접근성 이름·현재 값을 보존한다.
- 업데이트의 앱 재시작·준비 후 설정 잠금은 계속 보인다. 상세 설명은 펼칠 수 있고 오류·비활성 조건은 유지한다. 단축 근무·반차 설명도 같은 방식으로 정리한다.
- 테마 8개 2열·부엉이 5개·선택 테두리/체크는 유지한다. 테마 카드 내부 8pt·간격 10pt, 12pt regular 이름과 약한 비선택 경계를 적용한다.
- 설정의 출근 달력에만 작은 월 제목·중립 탐색 버튼·테마 강조색을 적용한다. `MonthCalendarView`의 다른 호출자는 기존 기본 표현을 유지한다.
- 플러그인 목록은 소개 카드 구성을 유지하면서 이름·설명·심볼의 강조를 줄인다.

## 검수와 확인

- Astra 사전 검수: 재시작/설정 잠금의 상시 안내, 스위치·Stepper 접근성 이름/현재 값, 공통 달력의 적용 경계, GroupBox 여백 중첩에 주의하도록 제안했다. 구현은 행 카드의 내부 패딩을 별도 지정하고 위 조건을 보존한다.
- Astra 최종 검수 및 포커스·달력 색 후속 검수에서 확정 결함이나 blocker가 없었다. 실제 포커스 추적은 소스 검토와 별도로 확인했다.
