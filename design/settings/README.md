# Mac 설정 디자인 규칙

이 문서는 HappyLulu Mac 설정 화면의 현재 개발 규칙과 디자인 리뷰 결정을 기록한다.
2026-11-11 사용자 제공 화면과 2026-11-14 이 Mac의 시스템 설정을 참고했으며, 아래 수치는 Apple의 공식 치수가 아니라 HappyLulu의 제품 규칙이다.
현재 구현과 기능 ID는 [디자인 명세](../../docs/DESIGN-SPEC.md), [기능 명세](../../docs/FEATURE-SPEC.md)와 함께 확인한다.

## 공통 배치

- 설정은 폭 230pt의 사이드바와 분리된 본문으로 구성한다. 기본 밝은 화면은 회색 사이드바와 흰 본문을 사용하고, 어두운 화면은 시스템 색상을 따른다.
- 화면 제목은 15pt semibold, 카드 제목은 13pt medium, 설정 항목명은 13pt regular, 보조 설명은 11pt regular다. 제목과 카드 사이는 10pt, 설정 구역 사이는 24pt다. 카드는 모서리 반경 12pt를 사용한다. 공통 글자·간격 값은 `SettingsStyle.swift`에서 관리한다.
- 테마를 바꾸어도 같은 사이드바·카드·제어 형태와 배치를 유지하고, 해당 테마의 배경·사이드바·카드·강조·글자색만 반영한다.
- 모든 사이드바 항목은 단색 파란색 Apple SF Symbols를 사용한다. 문양은 13pt regular·medium scale이며 20pt 슬롯과 행 클릭 영역은 유지한다. 다색 표현·그림자·겹친 하이라이트는 제거한다. 활성 창의 목록에 포커스가 있을 때 선택 행은 흰 아이콘과 글자, 목록이 포커스를 잃으면 선택 행은 시스템 글자색과 파란 아이콘을 사용해 네이티브 회색 선택 배경에서도 대비를 유지한다. 부엉이 앱 아이콘 선택은 별개다.

## 창 상단과 사이드바

- `happylulu` 브랜드는 macOS의 닫기·최소화·확대 버튼 오른쪽에 둔다. 앱이 창 버튼의 위치를 직접 조정하지 않는다.
- 브랜드는 장식 정보이며 창 버튼 입력과 제목줄 드래그를 가로채지 않는다. 접근성용 창 제목과 사이드바 항목은 유지한다.
- 사이드바 본문에는 브랜드를 중복 표시하지 않는다. 구형 macOS에서도 표준 제목줄과 버튼이 남아 있어야 한다.
- 본문 상단에는 현재 화면 이름을 15pt semibold로 표시한다. 제목 영역은 44pt이고 본문 스크롤과 분리한다. 제목 아래 첫 구역까지 12pt를 둔다. 설치된 플러그인은 해당 플러그인 이름을 표시한다.
- 기본 설정은 일반·외관·근무·플러그인 관리로 구성한다. 업데이트는 일반 하단, 출근 기록은 근무 하단에 둔다. 패널의 출근 기록 진입은 근무를 선택하고 기록 구역으로 이동하며 반복 진입에도 동작해야 한다.

## 일반 설정

- `HL-UI-007`의 일반 설정은 둥근 연한 카드에 관련 행을 묶는다. 행의 왼쪽에는 항목명과 짧은 설명·표시 예시를 위아래로 놓고, 오른쪽에는 해당 선택기 또는 스위치를 둔다.
- 일반은 `사용 환경`과 `업데이트`를 동급 제목으로 구분한다. 공통 행의 안쪽 여백은 가로 14pt·세로 12pt, 설명과 조작 사이는 12pt, 항목명과 설명 사이는 4pt다. 선택기는 필요한 폭만 사용하고 조작의 오른쪽 끝을 맞춘다. 행 사이에는 좌우 14pt가 들여진 구분선을 두며 긴 한국어·영어 설명은 고정 높이로 자르지 않는다.
- 언어 인사 예시는 제거하고 남은 시간·퇴근 예정 표시의 유용한 가상값만 `예시`로 표시한다. 계산 방식은 펼칠 수 있는 안내로 제공한다. 로그인 승인 상태와 조건부 허용 버튼은 계속 보인다.
- 기본 밝은 테마의 카드는 시스템의 연한 회색 표면을 사용한다. 색상 테마와 커스텀은 저장된 카드색을 사용하고, 배치 방식은 같다.
- 일반 하단 업데이트는 `현재 버전` 행과 오른쪽의 `지금 업데이트 확인` 버튼을 표시한다. 자동 확인·설치 스위치는 제거하고 기존 저장값은 유지한다. 데이터 보존은 짧게 표시하고 기존 자동 설치의 재시작·준비 후 잠금 안내는 펼쳐 볼 수 있다. 오류와 기존 비활성 조건은 유지하며 화면을 여는 것만으로 업데이트를 시작하지 않는다.

## 근무와 기록

- `오늘 근무`에는 기존 근무 유형 선택과 출근 수정·조건부 안내를 유지하고, `근무 시간`에는 근무·휴게 값을 공통 행 오른쪽에 둔다. 조작의 접근성 이름·현재 값과 기존 범위·증분을 보존한다.
- 즉시 반영 안내는 항상 보이며 단축 근무·반차 계산 안내는 펼칠 수 있다. 출근 기록은 같은 페이지 하단에 유지한다.
- 설정 안의 달력에만 14pt medium 월 제목·중립 탐색 버튼·테마 강조색을 적용한다. 다른 화면에서 쓰는 공통 달력의 기본 표현은 유지한다.

## 플러그인 설정

- `HL-UI-011`, `HL-UI-017`의 AI 사용량은 플러그인 관리에서 설치한 뒤 사이드바의 **AI 사용량**에서 설정한다. **사용량 보기** 스위치는 플러그인 사용 상태를 직접 제어하는 단일 스위치이며 일반 설정에 중복하지 않는다.
- 끈 플러그인도 설치된 항목에 남아 다시 켤 수 있다. 기존 활성화 선택과 연결·표시 설정은 보존하고, 설치 직후 기본 사용 상태는 꺼짐이다.
- 상세의 사용 스위치는 공통 행 오른쪽에 놓는다. 플러그인 관리의 소개 카드는 유지하되 이름·설명에는 공통 글자 위계를 적용한다.

## 외관 설정

- 기본 테마·여섯 색상 테마·커스텀은 2열에 모두 표시하고, 테마와 앱 아이콘은 고정 크기 테두리와 우상단 체크로 선택을 표시한다.
- 테마 카드 내부는 8pt, 가로·세로 간격은 10pt다. 비선택 바탕과 경계는 약하게 표시하고 선택 테두리는 2pt로 유지한다. 테마 이름은 12pt regular, 부엉이 이미지와 다섯 이름은 유지한다.
- 색상 편집은 테마 오른쪽의 **색상 설정…**에서 연다. 기본 테마는 시스템 색상을 따르며, 커스텀 색상은 재선택·다른 테마 전환 후 보존한다.

## 식별자와 검증

- 이 변경은 기존 `HL-UI-006`, `HL-UI-007`, `HL-UI-010`, `HL-UI-011`, `HL-UI-017` 및 `HL-GEN-003`, `HL-HIST-001/002`, `HL-UPDATE-001`의 진입 경로·디자인을 갱신한다. 새 기능 ID나 앱 bundle ID는 필요하지 않다.
- 기존 `settings-departure-switch`, `settings-usage-switch`, `settings-login-switch`와 접근성 이름·기능을 유지한다.
- 격리 검사에서는 사이드바와 8개 테마의 본문 배치, 창 버튼과 브랜드의 비겹침·드래그 통과를 확인한다. 실제 설치 앱의 창 버튼·드래그, 한국어·영어 줄바꿈, VoiceOver 및 구형 macOS 확인은 각각 별도다.

## 리뷰 기록

- 2026-11-14 적용: 사용자가 분석안 반영을 승인했다. [디테일 개선 적용 기록](2026-11-14-settings-detail-update.md)에 최종 수치, Astra 검수, 검사와 설치 결과를 구분해 기록한다.
- 2026-11-14 분석: [Apple 설정과의 디테일 차이 및 개선 제안](2026-11-14-apple-settings-detail-audit.md). 아이콘·글자 위계·설정 행·간격·제목의 원인과 수정 순서를 정리한 구현 전 제안이다. 현재 규칙과 기존 결정의 수치를 변경하지 않는다.
- 2026-11-11: 사용자 요청에 따라 구역 간격을 20pt에서 24pt로 늘리고, 브랜드를 신호등 오른쪽으로 옮기며 일반 설정을 행과 구분선으로 정리한다. Astra 사전 검수에서 제안된 간격·기존 ID 보존·창 버튼과 드래그 안전 조건을 반영했다. 로컬 개발 후보이며 배포나 사용자 수락을 뜻하지 않는다.
- 2026-11-11: Astra 최종 검수에서 구형 제목줄의 글자 대비와 최소 폭 검증의 범위를 지적해 각각 시스템 글자색 분기와 실제 820pt 행 범위 검사로 보완했다. 현재 Dev의 활성·비활성 선택 대비는 확인했고, 실제 제목줄 드래그·VoiceOver·구형 macOS 실기는 별도 확인이다.
- 2026-11-11: 사용자 피드백에 따라 일반 설정 행을 조밀하게 조정하고 사용량 보기를 AI 사용량 플러그인의 단일 사용 스위치로 이동한다. 설치·활성화는 별개이며 이전 선택값을 바꾸지 않는다. 이 기록은 로컬 개발 후보 기준이다.
- 2026-11-11: Astra 독립 검수에서 AI 사용량 상세 문서의 이전 일반 설정 경로를 발견해 수정했다. 고정 Dev 앱에서 일반 설정과 사용량 스위치의 기존 켜짐 표시를 확인했다. 실제 Dev 스위치의 켜고 끄기 조작은 사용자 설정 보존을 위해 수행하지 않았으며, 상태 변경·재시작은 격리된 합성 저장소에서 확인했다.
- 2026-11-14: 단색 파란색 사이드바·작은 화면 제목을 적용하고 업데이트/출근 기록을 일반/근무에 합친다. [결정과 Apple 설정 비교](2026-11-14-sidebar-and-navigation.md)에 범위·남는 차이·확인 조건을 기록한다.

## 팝업과 Mac 유틸리티

메뉴바 팝업은 오른쪽에 설정(gearshape)·종료(power) 버튼을 독립 배치한다. 각 클릭 영역은 28pt, 문양은 14pt이며 테마에 따라 배치를 바꾸지 않는다. 출근 시각 편집 중에는 먼저 저장하며 저장 실패 시 이동·종료하지 않고 편집을 유지한다. 새 화면 꺼짐 방지·마우스 휠 반전은 플러그인 설정에서 관리한다. [동작·검증 규칙](../plugins/2026-11-14-mac-utilities.md)
