# 설정 디자인 일부 복원과 메뉴 통합

2026-11-14 사용자 요청에 따른 로컬 Mac 개발 변경이다. 비교 기준은 이 Mac에서 직접 연 시스템 설정의 일반·Bluetooth 화면과 기존 사용자 제공 VPN 화면이다. Apple의 공식 치수나 모든 macOS 버전의 공통 규격으로 해석하지 않는다.

## 반영할 결정

- 사이드바는 사용자 후속 요청에 따라 단색 파란색 SF Symbols로 바꾼다. 다색 표현·그림자·겹친 하이라이트를 제거하고 활성 창의 선택 행에서는 흰색으로 대비를 유지한다. 앱 아이콘의 부엉이 표정 선택은 별개다.
- 제목은 사용자가 선택한 **상단의 작은 현재 화면 이름**으로 표시한다. 본문 스크롤과 분리하고 일반·외관·근무·플러그인 이름을 따른다. 큰 소개 카드는 추가하지 않는다.
- 기본 설정은 일반·외관·근무·플러그인 관리 네 항목이다. 업데이트는 일반 아래, 출근 기록은 근무 아래에 놓는다.
- 기존 출근 기록 진입은 근무 화면의 기록 영역으로 이동한다. 반복 진입과 기존 업데이트 목적지도 유지한다. 저장값·업데이트 실행 조건·출근 계산은 바꾸지 않는다.

## 확인 조건

- 최소 창 크기와 8개 테마에서 사이드바·제목·본문의 배치가 동일해야 한다.
- 일반에는 업데이트, 근무에는 출근 기록이 존재하고 과거 목적지는 해당 구역으로 스크롤되어야 한다.
- 출근 기록의 반복 진입, 사이드바 선택, 한국어·영어 제목 및 설치된 플러그인 제목을 확인한다.
- 실제 고정 Dev 앱의 화면과 서명·실행파일을 확인한다. 운영 앱·Dev 저장값은 보존한다.
