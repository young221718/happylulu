2026-10-19 사용자 결정: “앱 아이콘은 옛날게 더 좋고 눈 심볼만 저걸로 가자”.

앱 아이콘은 민트색 타일에 보라색 올루루와 시계가 들어간 기존 이미지입니다. 메뉴바에는 둥근 눈테, 큰 세로 타원 동공, 작은 반짝임과 부리가 있는 v3 단색 심볼을 사용합니다. v3 미리보기의 왼쪽 앱 아이콘은 이번 선택에 포함되지 않습니다.

브랜드 표기는 **happylulu**이며 **lulu는 항상 소문자**입니다. 공통 글꼴은 Pretendard Variable, 제목·브랜드700, 본문400, 버튼600입니다.

## 보관과 적용 상태

선택한 원본의 상대 경로와 SHA-256은 [selection.json](selection.json)에 기록합니다. 원본 파일은 편집하거나 교체하지 않았습니다.

이 문서는 디자인 선택을 확정한 기록입니다. 실제 앱 코드·앱 아이콘 등록·메뉴바 구현·배포는 변경하지 않았습니다. 기존 PNG의 타일 치수와 R을 새로 정규화한 것도 아닙니다. 메뉴바 심볼은 로컬 브라우저 18×18 CSS px 모형에서 확인했으며, 실제 AppKit 18pt의 1×·2× 화면 검증은 적용 단계에 남아 있습니다.

v1·v2·v3 시안과 사용자 참고 그림을 보존합니다. 다음 작업에서 앱 아이콘과 메뉴바 심볼을 같은 파일로 교체하지 않도록 이 선택을 기준으로 사용합니다.
