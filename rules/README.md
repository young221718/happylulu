## 공통 규칙과 재귀 적용

workspace-chanyoung 안에서는 [상위 공통 룰](../../../../rules/README.md)과 [통합 위키](../../../../wiki/index.md)를 함께 확인한다. 이 상대 경로는 해당 작업공간 배치용이며 독립 clone에서는 존재를 가정하지 않는다. 독립 checkout은 이 로컬 규칙과 [AGENTS 안내](../AGENTS.md)로 소유 범위·보존 제한·검증을 확인하고, 공통 문서에 접근하지 못한 사실을 작업 기록에 남긴다. 누락된 문서가 추가 권한을 뜻하지 않는다.

상위 공통 룰은 명시된 범위에 적용하고, 로컬·중첩 지침에는 그 영역의 추가 규칙과 차이만 둔다. 부모의 데이터·보안·게시 제한을 임의로 완화하지 않는다. 예외는 현재 사용자 결정, 출처, 이유와 적용 범위를 기록한다. 다른 Git root의 지침은 자동으로 읽혔다고 가정하지 않는다.

AGENTS.md는 작업별 문서 안내로 유지한다. 150줄 이내를 권장하고 200줄을 넘지 않으며, 별도의 파일 바이트 상한은 두지 않는다. 상세 규칙·작업 일지·명세 전문을 복제하지 않는다. override를 작성하면 대체되는 지침의 필수 계약과 문서 진입점을 유지한다.

## 문서 갱신

새 문서·이동 경로·폐기 상태는 [위키 목차](../wiki/README.md)에 함께 반영한다. 기존 문서와 날짜가 있는 의사결정·검증 이력을 보존하고 정본을 링크한다. 공통 지식은 상위 통합 위키, HappyLulu 지식은 이 레포 위키가 소유한다. Space에는 채팅별 목차·주제별 TODO·현재 결정·검증 결과와 정본 링크를 남긴다.
